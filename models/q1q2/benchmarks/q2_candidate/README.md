# Q2 候选区域正确性 benchmark

只读测试 `models/q1q2/feasible.py`，不修改生产代码。真值生成器不导入任何生产模块；运行器才调用 `build_source_set`、`check_candidate`、`SourceSet.contains/radial_interval` 和 `posterior_contains`。

从仓库根目录运行：

```bash
models/q1q2/.venv/bin/python -m models.q1q2.benchmarks.q2_candidate.generate
models/q1q2/.venv/bin/python -m models.q1q2.benchmarks.q2_candidate.run
```

依赖只有现有 venv 的 numpy 和标准库，无新增依赖。随机种子 20260911。`cases.jsonl` 保存输入、独立真值、方法、类别和反例；`report.json` 保存每例检查项、完整生产返回值、采样统计、失败详情、配对不变量和输入/生产文件 SHA256。重复生成的案例内容确定；报告时间和耗时自然变化。

## 独立真值及覆盖

- **四圆盘**：标准场景直接计算四个圆心 `5u±,1000u±` 到 q 的距离。包括 S、手算例、轴线右端、40 个方向的解析边界及边界内外 1e-5 米扰动、100 个随机点和其他对抗点。每一点配对 `rho_hi=1000/1500`；仅改变外径，最小半径仍为 1000。四盘真值还和独立极坐标复算交叉检查。
- **独立极坐标解析**：完整扇区中，低距离分支关于 r 为凸二次函数，高距离分支为仿射函数，故只检查径向端点和 1000 分界。角方向只检查角端点与 q 的同向/反向驻点。保存分别复算的 `g_low/g_high`；这不调用生产边界构造或枚举器。C_dir 用 q 在扇区内的最近角方向和径向投影求最近距离，保留 r=5 端点是否取得。
- **手算例**：q=(750,400) 的 r=1000 最坏距离为 486.5083580116992 米，r↓5 距离为 845.633461916022 米，g_H=-763309.6175847603 平方米，到角锥距离为 386.8497732345939 米；因此 C_sig/C_dir 均 IN。使用解析式，绝不把 486.5 当精确输入。
- **域外、裁剪、退化**：S=(2000,0) 向西零角宽观测给出精确线段 r∈[200,1500]；另有目标圆相切形成单点 F。非零角宽的域外裁剪例，IN 由完整扇区超集的解析保收/示向证明，OUT 由实际采样反例证明；不把完整扇区的极值误当裁剪后精确极值。
- **严格 5 米边界**：q=S；零角宽 q=(5,5) 的最近源仅在排除端点 r=5 取得，数学上仍属于 C_dir；q=(100,5) 的等号在实际源取得，数学上 OUT。覆盖两侧 1e-6 米扰动。C_dir OUT 的 near 反例必须在实际 F 内，不能把 r=5 极限点作为反例。
- **刚体变换**：24 例同步旋转/平移 S、q、目标圆心，与标准场景配对；另核验外径配对。所有动作仍在默认接口范围内。
- **不一致首测**：四例空 F，包括圆域远离角锥、接收距离不够以及仅接触被排除 r=5 的构型。按 PLAN §5.1 检查 `INCONSISTENT_FIRST_OBSERVATION` 状态和 `UNRESOLVED.reason`，不要求当前 API 抛出 Python 异常，不将空 F 的全称命题当作候选 IN。

## 定义级采样与反例

每个非空场景使用 2049 个角度 × 129 个径向位置，以及 12000 个独立随机角度/径向样本；裁剪到原始 F 定义。角度包含端点，r=5 用 5+1e-8 替代。另对每个 p 检查两个世界：最小允许 rho=max(1000,r1)，以及在允许区间内独立随机选择的 rho。最小 rho 检查是全 rho 量化的精确单调约化。

有限采样未发现违反只作弱交叉核验，不能证明 IN；`weak_comparisons_excluded` 是排除为 IN 证明的采样批次数，不是丢弃案例数。所有计分案例均有解析/超集证书或实际反例依据。每个 OUT 真值附 `(p,rho,kind)`，运行器再次按原始距离、角度和目标圆约束复核。信号极值若仅在 r=5 极限取得，则移动到 r>5 且仍严格违反的位置后才保存为世界。边界等号的解析构造按下述浮点容差复核。

实际本次累计对各候选检查 145621167 个源样本（场景间复用，非独立样本总量），对应两倍数量的世界检查。不据此给出漏检概率或全域认证。窄违反可能被网格漏掉，四盘边界用例和解析/实际反例证书独立于此网格。

## 判分与容差

- 长度比较 1e-7 米，平方残差比较 1e-5 平方米；生产 NumericPolicy 保持默认。四盘边界判别使用 1e-8 米，解析平方残差状态用 1e-5 平方米；离边界扰动显著大于这些阈值。
- 独立世界成员的闭约束容差：径向/目标圆 1e-8 米，角度 1e-10 度。实际 F 的 r>5 不加宽；闭包允许 r≥5−1e-8。对声称实际取得的见证，使用 70 位 Decimal 从返回的 binary64 坐标精确转换后复核 r²>25，不把 1e-8 当作额外净距。对标为未取得的上确界见证，允许距 5 米不超过 1e-8 的内圆表示误差；仍须满足闭包约束。报告中的角端点成员失败是相对于此明确数值合同，不声称为远离边界的几何错误。
- 每例分别检查 C_sig 和 C_dir 状态。数学等号边界用 `BOUNDARY`，S 按已知不变量明确期待 `IN`。仅在解析证实最近距离为 5 米且 q≠S 时，允许 PLAN 所述 `UNRESOLVED`；数学成员资格仍单独保存，不把 UNRESOLVED 说成 IN。
- 比较 g_L/g_H 的精确扇区/线段/单点例；一般裁剪的充分 IN 证书不比较极值相等。
- 返回源见证不与真值坐标比较，接受任意有效见证。信号 OUT 允许正确标注的极限分离约束，但案例另有真实违反世界。C_dir OUT 可由信号分离见证或实际 F 内的 near 见证证明；后者要求距离≤5，不能仅靠被排除端点的等号。OUT 见证不要求最大化信号残差；尤其 near 见证不必匹配 `max_violation`。IN/BOUNDARY 等非 OUT 返回的极值见证仍按 §5.4 检查残差，g_L/g_H 另行检查。
- F 点成员、极坐标区间及 near/direction 后验也分别核验。后验对照直接用原始角度和距离，并遵循同点固定反馈规则。
- 一例所有检查通过才计 pass；类别可以重叠，失败检查数不能相加作为失败例数。配对不变量失败也会计入案例失败。

## 分组报告与文档契约

`report.json.groups` 和每例 `results[].groups` 将三类结果分开：

- `core_membership`：两种候选状态的合同检查。另有 `binary_decisions.sig/dir`，仅统计显式 IN/OUT 的数学成员正确率；BOUNDARY、UNRESOLVED、空 F 分列，不冒充正确 IN。
- `witness_metadata`：见证闭包合法性、是否取得、分离有效性，以及非 OUT 极值见证的残差。统计适用案例数和检查项数；没有返回见证的 S/空 F 不作为“见证通过”凑分。OUT 若缺失见证则明确失败。
- `auxiliary`：F/后验成员、极坐标区间、g_L/g_H、真值反例复核、采样交叉核验及配对不变量。保留原始失败，不将它们混入核心或见证通过率。

每组同时给出案例通过率 `case_pass_rate` 与检查项通过率 `check_pass_rate`。顶层 `n_pass/n_fail` 仍是所有检查合取，兼容父 benchmark 汇总格式。

契约依据：PLAN §5.4 第 5 项明确允许标为未取得的上确界见证；§5.5 定义 C_dir 并区分实际取得和排除端点等号；§5.6 约定 S 与空集处理。文档不指定唯一源坐标，也不要求 near 反例同时是信号距离极值点。本次删除了旧运行器在 OUT 上附加的信号残差相等要求，并改正“距内圆很近就一定不是实际源”的过严检查。独立验证已确认多个不同 near 见证均被接受，错误远点/缺失见证被拒，正确的未取得信号极限被接受，排除端点的 near 等号被拒。

## 变换后边界探针的语义修正

源成员与后验 API 探针针对实际提交的 binary64 坐标，独立用距离和 atan2 检查 `r>5`、`r<=rho_hi`、目标圆内和角度闭边界，不给闭约束额外 slack。原来的世界见证 oracle 为解析边界的坐标表示保留 1e-8 米 / 1e-10 度裕度；该裕度不能直接用于要求严格开闭边界的 API 布尔值逐点相等。旋转/裁剪后的理论端点可能在浮点表示中略越界，现按提交坐标判定；没有删除探针，也没有允许任意边界答案。

`legal(..., boundary_slack=False)` 仅用于源/后验探针。解析 sector/four-disk 真值、世界见证容差、核心 sig_status/dir_status 及所有 IN/OUT 检查均不变。report 的 `source_probe_boundary_reclassifications` 逐例记录与旧探针 oracle 的差异。

重跑 531/531 通过（100%），29 例的边界探针语义得到修正；核心状态检查 1062/1062 通过。明确 IN/OUT 准确率：signal 438/438，direction 440/440；BOUNDARY、UNRESOLVED 仍独立统计，没有计作 IN。
