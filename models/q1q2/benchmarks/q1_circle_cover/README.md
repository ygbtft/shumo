# Q1 覆盖圆正确性 benchmark

在仓库根目录运行：

```sh
models/q1q2/.venv/bin/python -m models.q1q2.benchmarks.q1_circle_cover.generate
models/q1q2/.venv/bin/python -m models.q1q2.benchmarks.q1_circle_cover.run
# 或重新生成后立即运行
models/q1q2/.venv/bin/python -m models.q1q2.benchmarks.q1_circle_cover.run --regenerate
```

激活该 venv 后可直接使用 `python -m models.q1q2.benchmarks.q1_circle_cover.run`。仅使用标准库与生产已有 numpy，无新增依赖。失败时退出码为 1；报告仍完整写入 `report.json`。案例生成固定随机种子 20260911，每例 Welzl 使用 0、1、7、42 四个种子。文件路径相对模块位置解析。

## 独立真值

`generate.py` 不导入任何生产模块。对序列化的 binary64 坐标使用 `Fraction(float)` 得到精确有理值，枚举全部 1/2/3 点圆，以全局垂直平分线方程和精确 Cramer 法解三点圆，精确比较平方距离及包含性，选最小者。与生产的浮点线性求解、Welzl 增量及带容差枚举不共享代码或计算结果。平方根使用 80 位 Decimal，最终转换为 JSON 数值，同时保存半径平方与 Thales 量的精确分数字符串。

全对枚举得到直径与所有精确最远对；独立覆盖真值比较 `4R² <= d²`，并断言它与精确 Thales 符号一致。κ 从独立 R、d 计算；η 从各点至最远对中点的独立距离计算，不使用生产的 Thales→η 公式。最小圆支撑允许非唯一，检验 1–3 个不同有效索引、圆周接触以及该子集独立最小圆的圆心/半径。随机点集可以包含内部点，代表其凸包；所有极点均在输入内，不调用生产凸包或直径算法。

闭式族额外交叉核验枚举真值：点、线段、等腰/直角/钝角/锐角三角形、正方形、正 3–13 边形、等边三角形。等边族验证 R=L/√3、κ=2/√3、η=√3、T=L²/2 及 Jung 等号。正方形分别传入两条对角线，检验不同最远对的同一强制圆心。普通三点圆与强制边界圆单独调用，钝角三角形分别期望最长边圆与外接圆；共线或落入明示数值阈值的强制三点边界期望 `ForcedSupportError`。

## 覆盖范围与阈值

- 100 个随机点集；重复、单点、两点、共线、近共线；Thales 零残差内外侧。
- 旋转平移、反射并缩放 10⁻⁶、缩放 10⁶、平移至 ±10⁹ 的不变量压力测试，并新增缩放 10⁻³ 和平移至 ±10⁵ 的正常尺度对照。每个变换例重新计算精确真值，同时与原例生产结果核对半径、直径、κ/η 和覆盖状态。平移 ±10⁹ 属理论 API 压力输入，超过实际动作接口坐标限额。
- 等边三角形 L=1、20、20√3、36、40、1000 保存 §3.4 的三组 ±1° 观测、源点和站源距离。生成时独立检查全部顶点的角度成员关系及三条有效边界与三角形边重合。三条有效内侧半平面定义三角形，另一侧不截去顶点，故交集恰为三角形。L=20√3、36、40 的站源距离在 5–1500 米内；L=1000 只验证纯角锥几何，不声称可接收信号。
- 清除三段包括 0、20√3 和 40 等号、各分界两侧相邻浮点、36、负值。等边族同时测试其边长输入的清除分段；36 米三角形 R>20，40 米线段 R=20。`20√3` 等号以 `20*math.sqrt(3)` 的 binary64 表示约定；上下相邻浮点明确指定分段，不借重新平方改变等号语义。
- EMPTY、UNBOUNDED 期望 NOT_APPLICABLE；缺失直径端点与区域未决期望 UNRESOLVED；点的 κ/η 必须为 null。

## 容差与失败含义

报告内记录全部参数。长度/中心容差为 `2e-9 + 2e-10*d + 8*max_coordinate_ulp` 米；Thales 数值误差容差为 `2e-9 + 2e-12*d²` 平方米；κ/η 绝对容差 2e-8。不变量比值另允许输入平移舍入造成的 `16*ulp/d` 误差。强制外接圆也按输入几何尺度 d 使用上述长度容差，近共线病态外接圆并不因自身半径巨大而自动放宽。

状态判据单独使用合同默认 `τ=2(1e-10+1e-12*max(1,d))*max(1,d)`：精确 T>τ 必须 NO；0<T≤τ 必须 UNRESOLVED；精确 T=0 允许 YES 或 UNRESOLVED（边界浮点点积可能出现极小正值），不允许错误 NO。数学真假独立保存在 `mathematical_cover`，不会把 UNRESOLVED 当数学 YES。变换改变边界舍入符号时不要求数学真假严格相等，带外必须不变。

尺度分类在生成阶段按输入决定，与生产是否通过无关：坐标最大绝对值超过 10⁶ 米，或不同输入点的最小非零间距小于 10⁻³ 米，归入 `scale_limit`；其余为 `resolved_scale`，点/重复点零尺度按单点处理。这里的“特征尺寸”具体取最小非零点距，并非最小三角形高度。这是本 benchmark 约定的工程尺度范围，不是声称 binary64 在界外必然无法分辨；近共线条件数仍需单独关注。10⁹ 坐标的 ULP 约 1.19e-7 米，可能超过生产绝对长度容差；微小图形的叉积则可能落入默认平方容差，触发诚实未决。

`resolved_scale` 仍要求有限最小圆返回 OK 且通过原精度检查。在 `scale_limit` 中，minimum_circle/ordinary_three_point_circle 返回 NUMERICAL_UNRESOLVED 是合法结果：不对其不保证可靠的圆心、半径、支撑作精确解要求；覆盖函数内部 seed=0 最小圆同样未决时允许 κ=null，跳过依赖该 κ 的检查。可计算的覆盖状态、Thales、η、中点等仍核验，任何返回 OK 的结果仍按原容差检验。仅在某侧最小圆未决时不执行依赖其数值的不变量比较。

`report.json` 的 `scale_limits` 逐例保存输入尺度指标、接受未决的 API 调用及完整实际结果；这些是按声明合同通过，不表示全部求出了数值圆。没有根据失败名单豁免错误 OK 结果，也没有弱对照。异常保留 traceback；每个失败保存完整输入、真值、四个种子的实际结果及全部失败检查。分类标签可重叠，分类计数不能相加作为案例总数。

## 命名交叉校验锚点：对称四站正方形

`symmetric_four_station_square` 使用边长 a=20.660669√2 米、顶点 (0,0),(a,0),(a,a),(0,a)。按 PLAN §11.1 取 h=2a cot(2°)，第一站 (−h,0)，读数 1°，绕正方形中心精确旋转 90° 三次，得到读数 91°、181°、271°；半宽均为 1°。生成器独立核验各顶点角度成员关系及四条有效边界与四条边重合。此为纯角锥几何构造，不声称满足设备 1500 米接收上限。

真值为闭式 D=a√2=41.321338、R*=a/√2=20.660669、R*/D=0.5、覆盖 YES、清除分段 IMPOSSIBLE；精确枚举另行核验闭式数值。运行器既测试闭式顶点上的圆 API，又实际将四站观测送入生产 `q1.solve`，将其输出与闭式真值比较。生产求解仅是被测结果，不参与真值生成。`report.json.anchors` 保留生产链路的实测数值。
