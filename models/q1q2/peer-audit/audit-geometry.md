## 算法思路

### 角锥转半平面

`bearing_planes`（48–56）使用 `a·x≤b`。记检测点为 S，读数 θ，半宽 ε，v=x−S，两条法向分别是

```
n− = ( sin(θ−ε), −cos(θ−ε))
n+ = (−sin(θ+ε),  cos(θ+ε))
nF = (−cos θ, −sin θ)
b  = n·S
```

它们分别等价于 `cross(u−,v)≥0`、`cross(u+,v)≤0` 和 `u(θ)·v≥0`，符号正确。0<ε<90° 时前向约束冗余；ε=0 时两条边界只给直线，第三条约束把它限制为前向射线，因此第三条不能省。`solve_bearings`（183–187）确实保留全部三条。

θ 先 `%360` 再进入三角函数，没有对跨 0° 的区间做错误大小比较。以原始方向偏差作独立成员判定，对 39 个角度、每角 9 个非边界偏差的 351 次检查，半平面判定无不一致；包含 359.5°、负角度及多圈角度。

### 区域、凸包与直径

`halfplane_region`（144–180）先单位化法向，求零目标可行性 LP，再分别优化 ±x、±y。**在精确算术下，这个无界性判据是正确的**：非空集合若四个坐标极值都有限，就包含在有限矩形内；无界多面集必有某个坐标目标无界。这与“只检查四个坐标轴是否是衰退方向”不同，不能因设计选择了切向枚举就否定四目标 LP。

确认有界后，代码收集四个 LP 极值点，加上所有满足约束的非平行边界交点，然后求凸包。完整边界对枚举在非空有界多面集上是有效算法，包括点与线段；其约束检查阶段为 O(M³)，无需与设计的双端队列实现相同。

`hull`（14–25）是单调链：精确去重、剔除非左转，通常得到逆时针凸包，并保留精确共线点集的两个端点。数学步骤正确，浮点退化处理另见下文。

`diameter`（91–98）计算全部顶点对的平方距离并取最大值，时间及存储均为 O(V²)。对于完整凸包，直径在顶点对取得，算法成立。它不使用旋转卡壳，因此不存在卡壳平行边推进时漏掉相等面积候选的问题。正方形两条对角线、等边三角形多组最远对都参与计算；`argmax` 只返回一组，不是漏算最大值，也不必为了覆盖定理返回全部最远对。规范化顶点、索引及独立于输入顺序的 tie 合同则没有提供。

### 裁剪与最小圆

`clip`（28–45）是闭半平面 Sutherland–Hodgman 裁剪的实现，交点插值方向正确，空集、单点和线段可以进入。它先把边界向外移，因此实际裁的是外包半平面，而非精确输入半平面。

`minimum_circle`（113–132）采用固定种子 42 的三重随机增量循环。最内层需要经过三个强制支撑点的外接圆，正常非共线时调用外接圆是对的，不能笼统改成“钝角三点就用最长边圆”。末尾按全部输入点到圆心的最大距离补大半径，可修复漏包，但不能证明圆心仍然最优。

## 正确性问题（真 bug，带 file:行号）

### 1. 不可行被当作可行，继而返回确定的无界或线段

**位置：`geometry.py:152–162`；额外传播位置：`geometry.py:165–178`。优先级：高。**

LP 只设置 `method="highs"`，没有对返回点复查原约束，也没有对冲突的小间隙作后备判定。实跑环境 HiGHS 默认 `primal_feasibility_tolerance=1e-7`。例如

```
x ≤ 0
x ≥ 10⁻⁸
```

显然交集为空，但可行性 LP 返回成功和点 `(1e-8,0)`，原约束最大违反量是 `1e-8`。随后 y 方向无界，于是函数返回 `unbounded, diameter=inf`。这不是“有可行集但精度不足”：输入根本没有可行点，衰退方向即使存在也不能证明空集无界。

相同问题覆盖 `tiny_gap_8/10/12/14`。还可追加 `y≤0, −y≤0`，这时函数返回 `segment`、端点 `(0,0)` 和 `(1e-8,0)`、直径 `1e-8`；即使不走无界分支，也会凭容差制造非空确定解。165 行未经残差检查就纳入 LP 极值点，171 行又接纳违反原约束的交点，进一步固化了错误。

要求并非一定求出这些病态例的精确答案；没有足够证据时返回 `numerically_unresolved` 是可接受的。当前返回的是确定类别，因而是真 bug。

### 2. 小系数在 LP 中丢失，将有限三角形判成无界并给错直径

**位置：`geometry.py:151–162`。优先级：高。**

取 δ>0：

```
y ≥ 0
y ≤ δx
δx + y ≤ 1
```

精确顶点为 `(0,0)`、`(1/δ,0)`、`(1/(2δ),1/2)`。在本测试 δ≤10⁻¹⁰ 时，直径恰为 `1/δ`，衰退锥只有零向量：齐次约束给 `vy≥0`、`vy≤δvx`、`δvx+vy≤0`，合起来只能 vx=vy=0。

当前 HiGHS 默认 `small_matrix_value=1e-9`；法向归一化后 δ 分量仍小于此阈值，求解表现等同于漏掉了决定 x 有界性的微小系数。实跑 ±x LP 均报无界，代码直接返回 `inf`。δ=`1e-10/1e-12/1e-14` 三例均复现。

这是确定的有限值→无限值错误，不是直径顶点对循环的错误，也不是面积阈值造成的错误。只调可行性容差不能解决小矩阵元素阈值；代码还缺少对 LP 无界结论的原约束见证复核。Q1 是纯角锥/半平面模型，不能用源物理区域只有 1800 米来为这个通用内核的误判免责；这些例子属于通用半平面压力测试，并非声称是普通 ±1° 实测场景。

### 3. 用精确浮点凸包的顶点数判维数，点和线段生成伪高维区域

**位置：`geometry.py:15`、`geometry.py:21`、`geometry.py:165–173`、`geometry.py:176–178`。优先级：中。**

同一个数学交点可以由 LP 和不同边界对算出相差一两个 ulp 的坐标。`set(tuple(...))` 只去除位级相同的数值，叉积与零直接比较又把微小非共线误差当成真实拐角，最后以顶点数判断维数。

最直观反例是 `(0,0), 0°±0°` 与 `(10,0), 180°±0°`：交集应为 `[0,10]×{0}`。由于 `sin(π)≈1.2246467991473532e-16`，再叠加交点残差放行，返回三点 `(0,0)`、`(10,0)`、`(0,1.2246467991473533e-15)`，状态是 `bounded`（二维多边形）。重复/打乱观测同样出错。

旋转的单点 `(-1.2,3.4)` 返回两个相差 `2.220446049250313e-16` 米的点，状态 `segment`；旋转线段 `[(0,0),(6,8)]` 返回三个伪顶点，状态 `bounded`。这些维数是错的，但四例的直径都在夹具容差内，不应夸大成显著位置或直径误差。

不能简单用面积阈值压扁所有细长多边形；需要结合原约束、相对尺度、仿射维数及数值不确定性。设计允许证据不足时未决，当前代码没有做这一层判断。

### 4. 最小圆在小尺度上把良态锐角三角形当成共线，补半径后仍非最小

**位置：`geometry.py:104–108`、`geometry.py:130–131`；更小尺度还涉及 `geometry.py:121–129`。优先级：低于上述分类错误。**

取边长 s=`1e-7` 米的等边三角形：

```
(0,0), (s,0), (s/2, sqrt(3)*s/2)
```

正确圆心为 `(s/2,s/(2√3))`，半径 `s/√3=5.773502691896258e-8`。实跑得到圆心 `(5e-8,0)`、半径 `8.660254037844386e-8`，是最优半径的 1.5 倍。

根因是 `abs(det)<1e-13*max(1,|ab||ac|)`：小尺度时右侧固定为 `1e-13`，一个形状完全良态的等边三角形也被走入“共线”回退。该回退取最长边中点再放大半径，只保证覆盖这三点，既不是外接圆，也不是一般的最小圆。s=`1e-10` 时固定 `1e-9` 包含容差还会跳过所有更新，最终只在首点处扩圆。

此问题必须准确界定：函数注释已称末尾半径为上界，新增反例也没有漏包；错误在于把其结果当成精确/可靠的“最小覆盖圆”。绝对误差很小，不影响这里普通米级案例的既有成绩，但无数值状态的通用 MEC 接口不能给出全尺度最优保证。

辅助验证函数 `minimum_circle_enumerated`（135–141）同样调用这个 `circumcircle`，并以固定 `1e-7` 放宽包含判定；对 `[(0,0),(5e-8,0)]` 实跑返回圆心 `(0,0)`、半径 0，实际不覆盖第二点。因此它不是对上述尺度问题独立、严格的验证器。该函数不在 Q1 主流水线中，不能把它的漏包冒充主算法已发生漏包。

### 其余边界与数值风险

- **空/点/线段/多边形/无界：**都有代码路径，常规解析例能正常处理，但不能因此声称各类都能正确识别。全平面由空观测进入 LP 后返回无界；零法向配负常数直接返回空，其余零法向被删除，数学上正确。
- **衰退方向：**162 行只返回状态、空顶点列表和无限直径/半径，没有可行点或衰退方向。因此“无界是否给方向”的答案是没有。这是结果见证缺口，不等于四目标 LP 数学判据本身错误。
- **ε=90°：**49–50 行明确抛出 `ValueError`，不是正确实现半平面退化，也不是误判成空。数学上可以支持为 `u(θ)·v≥0`，但当前明确只支持 `[0,90)`。这导致 75 个夹具的原生测向 API 不支持；属于范围缺口，不能算 75 个错误答案，也不能计作通过。
- **近平行：**168 行将归一化法向行列式绝对值小于 `1e-15` 的边界对直接跳过，无病态标志或后备复核。被跳过的交点可能是有限但很远的关键顶点；四个坐标极值不足以替代任意多边形的完整顶点集。此处有漏顶点风险，但本次三例长三角形已在 LP 无界分支提前失败，不把它们重复归因于这条阈值。
- **容差不统一且不平移不变：**LP 容差、交点接受阈值 `1e-7+1e-11‖x‖`、精确凸包叉积、裁剪 `1e-8`、圆包含 `1e-9`、验证器 `1e-7` 分别独立。交点容差依赖世界坐标到原点距离，平移至 x≈2e6 米可放宽至约 `2.01e-5` 米；并非依据局部区域尺度。没有统一条件数或残差状态。整体没有强制把歧义标为未决的机制。
- **裁剪是明确外包：**36 行实际使用 `n·x≤b+1e-8 max(1,‖n‖)`。单位法向时是 1e-8 米外移；任意小法向时按空间距离计算的外移更大，因此半平面等价缩放也会改变裁剪结果。ε=0 的精确射线在二维输入上会被裁成薄带/薄多边形。这不是精确保维数，但注释已说明外移，适合作为保守候选区域操作，不能用其结果代替精确 Q1 分类。
- **`bearing_clip` 的前向约束：**61 行对正 ε 只裁两条边界，在精确数学中可以；外移后冗余性不再严格成立。原点朝东 ε=`1e-10°` 时，单点 `(-1000,0)` 仍会被保留，因为两条单位法向的违反量都约 `1.745e-9<1e-8`。它位于后方，是很松的外包，不是精确角锥成员。正常 ε=1° 后方放行深度约 `1e-8/sin(1°)=5.73e-7` 米，影响很小。此问题没有进入使用全部三条未外移约束的 `solve_bearings`。
- **没有大方框偷换 Q1：**`halfplane_region` 没有初始有限包围框；`solve_bearings` 也没有目标圆或接收圆。`update_region`（74–81）另用 1800 米目标圆与 1500 米接收圆的外切多边形，这是物理候选集外包入口，不属于纯 Q1。不能仅因同文件有有限多边形裁剪就指控 Q1 造假。

### 题面、附件2与默认角界

附件2 §1.1–1.2、§2.3、§7.3 写明东为 x 正向、北为 y 正向、东 0°逆时针，示向度从检测点指向干扰源；本实现符合。角锥包含检测点本身是闭几何模型选择，与 Q1 设计一致，不把设备 near 反馈当作正常示向。

需要区分两个默认值：`solve_bearings` 默认 **1°**，与理论 Q1 一致；`bearing_planes/bearing_clip/update_region` 默认 **1.01°**（6、48、59、74 行），注释说兼容截断误差。1.005° 是“先 ±1° 再最近舍入”假设下的外包，1.01° 则更宽；附件只说明 ±1°和两位小数，没有确认具体舍入过程。1.01° 作为说明了假设的保守模型可以接受，但直接调用底层默认接口所得区域不能称作精确 ±1° 区域。扩大角界会改变区域及直径，这是模型差异，不是法向符号错误。

## 与我们实现的差异

以已审定 `PLAN.md` §2、§3 为规范对照，并抽查了 `/Users/flower/math/2026/B题/models/q1q2/geometry.py` 当前实现；不假设“与我们不同”就一定错误，也不以我们实现作数学真值。

| 方面 | NTJ_B 当前实现 | 我们的设计/当前实现路线 | 审计判断 |
|---|---|---|---|
| 角锥 | 三条单位法向，θ 归一化 | 相同三条约束 | 核心公式相同且正确 |
| 非空/无界 | 1+4 次 HiGHS LP，直接解释状态 | 增量边界可行性、原残差复核、非零衰退方向 | 两路线均有数学依据；NTJ_B 数值状态与见证不足 |
| 顶点 | LP 极值点 + 全边界对交点 + 凸包 | 排序双端队列，退化枚举后备 | 枚举可合法替代；不是必须照抄双端队列 |
| 数值处理 | 多组固定阈值、精确去重、按顶点数判维数 | 平移尺度化、数值策略、近重复/共线规范化及未决状态 | 当前真错误集中在这一层 |
| 直径 | 全对枚举，一组端点 | 旋转卡壳、平行边 tie、枚举验证 | 两者都正确；对方成本较高但没有卡壳漏对问题 |
| 最小圆 | 三重随机增量，近共线退回扩大圆，末尾补半径 | 强制三点与普通三点问题区分，支撑/残差及异常复核 | 通常输入正确；对方全尺度最小性保证不足 |
| 直径圆覆盖 | 本文件没有 Thales 最大残差/反例顶点接口 | 检查全部顶点 `(X−A)·(X−B)` 并给见证 | 功能缺口，不应把 `radius` 默认为 d/2 或覆盖布尔值 |
| 90°、无界见证 | 前者拒绝，后者不输出方向 | 90°半平面、可行点和衰退方向 | 接口范围与可复核性差异 |

不能用“两种最小圆程序互相比对通过”替代独立数学核验：其共同 `circumcircle` 和包含容差已经给出小尺度共同盲点。同样，我们设计要求的数值未决是证据不足时的合法输出，不要求对方为每个极端例引入高精度库，但要求它不要输出已被原约束反驳的确定结论。

## 总体判断

**不能认定 NTJ_B 的 Q1 通用几何流水线实现正确。** 它有合理且在普通构型上有效的算法骨架；角锥符号、前向含义、坐标约定和全对直径无需推翻。但分类层存在可复现的真错误，其中空集→非空、有限集→无界是数学结论错误。退化维数问题虽然通常只带来 ulp 级几何扰动，类别本身仍错。

对 README 的最终裁定是：**11/11 都不是可接受的未决；4 例空集误判、3 例有界性及直径错误、4 例维数错误但直径在容差内。** 75 个 90°案例是明确不支持，另行列出。小尺度 MEC 反例属于额外发现，应限制“最小圆”保证，不能据此否定已通过的普通尺度圆结果，也不能将其描述为主算法漏包。

import numpy as np
from geometry import halfplane_region, solve_bearings, minimum_circle

# 应为空，当前返回 unbounded / inf。
print(halfplane_region([[1, 0], [-1, 0]], [0, -1e-8]))

# 应为有限三角形，直径 1e10；当前返回 unbounded / inf。
d = 1e-10
print(halfplane_region([[0, -1], [-d, 1], [d, 1]], [0, 0, 1]))

# 应为线段；当前返回二维 bounded。
print(solve_bearings([([0, 0], 0), ([10, 0], 180)], error_deg=0))

# 真最小半径为 s/sqrt(3)，当前结果是它的 1.5 倍。
s = 1e-7
print(minimum_circle(s * np.array([[0., 0.], [1., 0.],
                                   [.5, np.sqrt(3)/2]])))
