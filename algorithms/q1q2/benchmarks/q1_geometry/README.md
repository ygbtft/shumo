只读测试 `algorithms/q1q2/geometry.py` 的 `wedge_halfplanes`、`intersect_halfplanes`、`convex_hull`、`diameter`。**真值生成器不导入任何生产模块**，也不以生产结果筛选案例、调整真值或容差。固定随机种子 `20260911`。

从仓库根目录运行：

```sh
.venv/bin/python -m pip install -r algorithms/q1q2/benchmarks/q1_geometry/requirements-bench.txt
.venv/bin/python -m algorithms.q1q2.benchmarks.q1_geometry.generate
.venv/bin/python -m algorithms.q1q2.benchmarks.q1_geometry.run
# 重建真值并测试：
.venv/bin/python -m algorithms.q1q2.benchmarks.q1_geometry.run --regenerate
```

激活该 venv 后亦可直接使用 `python -m algorithms.q1q2.benchmarks.q1_geometry.run`。有失败时退出码为 **1**，仍完整写出报告；全部通过为 0。案例不存在时自动生成。`cases.jsonl` 中的分数字符串可无损还原为 `Fraction`；`report.json` 的 `results` 保存所有逐例比较，`failures` 完整保存失败输入、期望、实际、误差与失败检查。非有限直径序列化为 `null`，由 `status=UNBOUNDED` 区分空集及数值未决。源码与案例 SHA-256、依赖版本、随机种子和运行时间均入报告。

## 真值独立性

1. **精确可行性**：对有理半平面 `a*x+b*y<=c` 用 Fourier–Motzkin 消去 y，解一维闭区间，再回代得到精确可行点。它不是生产的增量边界可行点法。
2. **精确无界性**：对齐次系统依次附加 `x=1`、`x=-1`、`y=1`、`y=-1` 后执行同一消元。非零衰退向量总能正比例缩放成其中之一；这不是仅检查四个轴向向量，也不是生产的边界切向枚举，更没有大方框裁剪。空集先行排除。
3. **精确顶点**：枚举非平行边界对，解 Fraction 交点并用全部原约束精确过滤。用 Fraction 的 Jarvis 包裹算法去掉共线内部点并给出逆时针凸包，与生产的浮点单调链独立。点、线段、多边形以精确顶点数分类。
4. **精确直径**：在规范化精确顶点集上枚举所有点对，保存最大有理平方距离和全部最远索引对；展示直径才开方。另把这些独立顶点直接输入生产 `diameter`，隔离上游交集/凸包错误。整数点云包含重复点、内部点、共线点，直接测试生产 `convex_hull`。
5. **独立 LP**：SciPy HiGHS `linprog` 先做可行性，再最小化 ±x、±y 判断有界性。变量显式不设上下界。保存五次状态、可行点和与精确分类的一致性。LP 只区分 EMPTY / BOUNDED / UNBOUNDED，不用浮点 LP 区分点与线段。LP 与精确真值不一致时列入 `lp_disagreements`，**不以 LP 覆盖精确答案，也不算作生产失败**。
6. **闭式交叉核验**：生成时断言射线交点、相向线段、背向空集、单角锥、正方形、正交双站和正 N 边形的解析分类/直径成立。射线与正方形另核对解析顶点。正交双站取 `(-a,0), (0,-a)`，方向 0°/90°，`t=tan(e)`，直径为 `2√2*a*t/(1-t²)`。正 N 边形内切圆半径 r=10，直径为 `2r sec(π/N)`（偶数）或再乘 `cos(π/(2N))`（奇数）。既测半宽 90° 支撑半平面族，也测真正半宽 1° 的角锥族：检测点沿边的负切向足够远移，使上边界和前向约束在整个外接圆上冗余。
7. **不变量**：对基础精确半平面施加有理正交旋转 `(cos,sin)=(3/5,4/5)`、反射、10⁻⁶/10⁶ 缩放及平移；对观测乱序、重复、加入远处冗余半平面，另用有效切割测试直径不增。每个变体仍单独生成独立真值；生成时先验证真值之间的关系，运行时再核对生产结果之间的关系。

### 角度的数值语义

直接半平面与点云以输入有理数为精确数学对象。观测坐标/角度按 JSON 十进制值转 Fraction；角函数由 **mpmath 80 位精度**计算，保留 **65 位十进制有效数字**后转有理数，再构造边界法向。正交/反向/45° 恒等式单独规范化，使零宽射线、轴向退化及正方形对称关系精确保留。真值不读取生产的三角函数或法向量。

非特殊角度的“精确”指该显式有理法向近似系统，而非对超越数的符号认证。65 位误差远小于本案例的最小 10⁻¹⁴° 半宽与浮点比较容差；仍不宣称这套实现认证了任意无限病态三角系统。规则多边形站点在 JSON 中为 binary64 计算后导出的十进制近似值，闭式检查留有 10⁻¹² 绝对/相对余量。实际精确答案始终以保存的 `oracle_halfplanes` 为准。

## 覆盖与判定

- 随机观测 N=1、2、3、4、8、16、32，既有含已知源点的构型，也有任意方位的可矛盾构型；另有随机整数法向约束和 1 至 300 点的凸包点云。
- 退化：N=0 全平面、单射线、单角锥、半平面、直线、条带、点、线段、空集。
- 对抗：跨 0°/多圈示向、近平行边界、近共线检测点、10⁻⁴ 至 10⁻¹⁴ 的薄宽/间隙、极窄角域、直径至 10¹⁴ 米的长三角形、平行边/多解最远对。
- 闭式：两射线交点、相向/背向共线射线、不同尺度的正交双站、两角锥正方形、N=3 至 64 的规则族以及 1° 规则族。
- 不变量不只自比：即使基础案例已失败，变体也与其独立真值比较，防止两个同样错误的生产结果互相“证明”。

分类必须完全相同；生产 `NUMERICAL_UNRESOLVED` 记为未通过，另统计为数值未决，**不等同于已确定的错误分类**。有界顶点分两项检查：`vertices`/`hull_vertices` 检查忽略定序后的双向几何覆盖；`vertex_normalization` 检查数量相同及容差内一一匹配。近重复点可通过几何覆盖，但仍因输出规范化合同未满足而使整例失败，不再描述为几何集合真错。还检查严格逆时针凸性、可行点、顶点约束残差、非零衰退向量、直径/平方直径、端点距离、端点成员和索引。独立顶点能精确表示为 binary64 时，额外核对最远对的字典序 tie rule；其他浮点近并列只要求返回一个达到直径的合法点对。

### 容差（运行前固定，不按失败调整）

| 量 | 判定阈值 | 依据 |
|---|---|---|
| 长度/直径 | `1e-8 m + 1e-9 * expected_diameter` | 小尺度由绝对误差限制；大尺度容许 float64 尺度/交点运算误差，不把巨大数值的微小相对误差误报 |
| 顶点距离 | 上式 + `32*ulp(max_abs_expected_coordinate)` | 平移后的坐标舍入独立于几何直径；仍要求顶点数量及一一对应 |
| 平方直径 | `length_tol*(2*d+length_tol)` | 从长度误差传播，单位 m² |
| 可行点残差 | `1e-8 m + 1e-12 * max(1, abs(point_coordinates))` | 对单位法向计长度残差，允许点坐标舍入 |
| 单位衰退方向 | 最大单位法向点积 ≤ `1e-10` | 接受任意合法方向；要求有限且非零，正比例缩放不影响判定 |
| 角锥法向 | 向量距离 ≤ `radians(1e-10°)` | 独立高精度法向与生产 binary64 法向比较 |
| 角锥 offset | `1e-8 m + 1e-12*abs(expected_offset)` | 系数归一化后的长度误差 |
| LP | primal/dual `1e-9` | HiGHS 浮点数值容差；极窄间隙不能据此认证 |

绝对/相对误差同时保存。特别地，远小于 10⁻⁸ 米的直径可以有较大的相对误差而仍通过长度检查，不能把“通过”解读成该尺度的高相对精度保证。精确分类与顶点数量不受长度容差豁免。最大误差统计只针对实际返回数值的案例；缺失直径另以检查失败记录，不能把 null 当成零误差。

## 比较器复核与报告归因（第二版）

**衰退方向非唯一。** 旧运行器已按齐次不等式校验，并未与 `ground_truth.recession_direction` 比较相等；该真值向量仅是存在性见证。这次将检查提取为 `recession_witness`，明确拒绝缺失、零、NaN/Inf 向量，先除最大绝对分量再单位化，防止巨大向量的范数溢出或极小向量归一化失真。对所有独立有理法向用 Fraction 计算点积；记录严格可行或只在方向舍入带内可行。任意满足条件的方向都可通过，不要求单位长度、不要求与真值同向（直线允许正反两向），全平面接受任意有限非零方向。实际 offset 不参与齐次判定。

**顶点定序、集合和输出规范化分别报告。** 原匹配已是无序二分图匹配，本次未修复一个并不存在的“固定定序比较”问题。新增 `diagnostics.vertices`：

- `equivalent_unordered_vertices`：无序一一匹配成立。
- `same_geometry_normalization_defect`：双向 Hausdorff 误差在容差内，但有近重复点/数量或匹配冲突；属于生产输出规范化问题，不能据此说区域几何错误。
- `vertex_set_discrepancy` / `missing_vertex_set`：明显不同或缺失的顶点集。
- `outside_tolerance_needs_numerical_review`：超过原容差但在其 10 倍内，作为数值复核提示；**10 倍只用于归因，绝不放宽通过阈值**。
- `upstream_numerical_unresolved`：生产上游未决；同时保存 `geometric_comparison`，不把缺失输出或未决误差混同于独立顶点提取真错。

逐例另存实际/期望顶点数、Hausdorff 误差、误差/容差比、未匹配索引及上游状态。循环移位、任意排列不影响集合比较；逆时针严格凸性仍是单独的生产接口检查，不能用重排结果替生产修正返回值。

**容差复核结论：保留原绝对/相对阈值。** 当前 12 个纯规范化失败的 Hausdorff 误差均远小于原阈值，放大顶点容差不会解决其近重复点问题。两个仍失败的 `vertices` 检查来自冗余约束案例，误差为原阈值的约 3.76 倍和 4.65 倍，且生产自己返回数值未决；将其标为上游数值问题并保留超容差记录，没有证据据此放宽阈值。大尺度案例的相对阈值本来较宽，报告明确保存逐例阈值；它不是严格前向误差认证。

`comparator_self_checks` 为不调用生产函数的 17 项自检：不同合法方向、巨大/次正规缩放、全平面、直线两向、非法方向/零/非有限值，以及顶点循环移位/反序、重复点、缺失角点和容差内外扰动。自检失败会中止运行，不写成生产通过。

### 历史真 bug 与 benchmark 自身改动分开

`regression_baseline.json` 固定保留首次 285 例运行的结果及生产/案例 hash；运行器不会覆盖它。原案例和独立真值全部保留，没有删例、xfail 或豁免。报告包含：

- `confirmed_production_bugs`：14 个历史单角锥未决真 bug 的旧状态、当前状态及生命周期。仍失败记 `confirmed_bug_waiting_for_production_fix`；修复后记 `resolved_regression_pass`。
- `benchmark_corrections`：证书比较加固、顶点失败归因拆分、容差复核诊断；不把它们记作生产修复。
- `baseline_comparator_recheck`：**把新比较器作用于保存的旧生产输出**，隔离生产并发修复的影响。本次旧输出依然 248 通过 / 37 未通过，比较器改动没有改变任何旧案例的总 pass/fail。
- `baseline_comparison`：当前与旧报告的通过变化、生产 hash 是否变化、案例 hash 是否一致。每例 `assessment` 同时标注历史/当前通过情况、顶点问题类型和回归状态。
