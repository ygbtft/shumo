# Q2 最坏定位直径与第二点选择 benchmark

本目录只读调用生产模块，不修改生产代码。真值模块 `generate.py` 不导入任何生产模块；只依赖 Python 标准库与已有 NumPy。随机种子为 20260911。

从仓库根目录运行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -m algorithms.q1q2.benchmarks.q2_worst_diameter.generate
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -m algorithms.q1q2.benchmarks.q2_worst_diameter.run
```

失败时 runner 写完完整 `report.json` 后退出 1，这是测试结果而非运行中断。案例生成可复现；报告时间、耗时会变化。报告保存被测模块 SHA256、每例输入、真值、实际值和每条独立判定。类别标签可重叠，不应把分类计数相加。

## 真值与判定口径

J 是连续集合上的上确界，生产 `J_hat` 是 `NUMERICAL_CANDIDATE`。本 benchmark **不把样本结果称为精确连续 J，也不把选点结果称为全局最优解**。

1. 独立稠密采样：直接从首测位置、方位、半宽和目标圆方程解射线圆盘交，每角 113 个径向点、35 个角度，不调用生产的 F 成员判据、径向参数或采样器。首测严格距离边界向内偏移，角端点通常向内移动约 1e-12 比例，新增 ε₁<0.01° 的极窄角使用 1e-8 比例以避开角度规范化舍入，闭径向端点移动 1e-9 m。这些偏移只使下界更保守。
2. 独立可达点对 oracle：朴素枚举全部无序点对（逐行 NumPy 计算，不用凸包/卡壳）。两点均距 q≤5 属 near；两点均距 q>5 时，用原始 `atan2` 和 `atan2(sin Δ, cos Δ)` 核对最短圆周夹角≤2ε₂，保存弧中点共同读数与源点见证。角度保留 1e-14 rad 内缩，避免把不合法阈值点误作反例。按 §6.2 交换有限反馈最大值与点对最大值，与枚举每个反馈后验再求直径等价。q=S 单独按原地规则取 F 样本直径。另在生产输入点云上也用独立全对枚举求有限点云真值，以区分采样误差和评分/直径实现错误；此项不作为连续 J 真值。
3. 显式反馈 oracle：另对小点云枚举以每个源方位为左端的全部 2ε₂ 圆周窗口及 near 分支；对窗口内点集用 Python `combinations` 全对求直径。任意有源点的可实现弧可平移到首个源方位而不丢点，因此有限点云枚举完整。用于跨零度、5 米两侧/等号、单点构型。这些案例只检查精确有限点云目标。
4. 闭式线段：ε₁=0，目标圆圆心 ((a+b)/2,0)、半径 (b−a)/2，精确构造 F=[a,b]×{0}。q=(0,H)，距离均>5；J=b−max(a,H tan(arctan(b/H)−2ε₂))。另有 F 全在 near 盘内与 q=S 的直径恒等式。三级源采样与开启 `refine_pairs=True` 的点对细化分别报告；各组具体网格和迭代次数见报告配置。
5. 单调性：固定点云增加 ε₂；固定保收 q 扩大 F（累积原有源点）；生产三级采样的集合包含关系和 J 序列。每个固定 q 的 near 补点也检查嵌套，报告丢失点数量与实例。扩张案例另用标准扇形端点闭式确认 q 保收。
6. 短基线：独立计算 arcsin(10/500)+arcsin(10/1500)<2°，得到 V(10)≥1000 m，不调用生产短基线函数。检查 `select_second_point` 与预算 0/5/10 m 的 `movement_frontier`，核验不同点、预算、下界、独立可达点对、并列时最短移动和曲线单调性。预算 0 核验无不同点与原地基线，不能把空候选当作定位成功。
7. 条件 R 与清除：对精确已知线段 K，独立枚举 1/2/3 点支撑圆并检验全点覆盖，求 R(K)，按 R≤20 判 E20 非空。覆盖原地可清除、需移动、R=20 阈值和 R>20 不可能案例。R=20 时生产因严格裕量返回 `NOT_YET_GUARANTEED` 合法；未保证不等于数学上 E20 为空。推荐点的条件诊断另检查支撑点 R 与独立后验采样对覆盖声明的必要条件。

三态由 `diagnostics.clearance_summary` 输出，`score_point` 仅输出 J 与 near 可能性。R(K) 是具体反馈的条件指标，既不是 J_R，也不参与生产的并列排序。本 benchmark 的并列排序检查使用返回候选的 J 值；这属于排序接口检查，绝不将这些值当作独立连续真值。

## 容差

- 独立实际可达下界：生产 J_hat 不得低于它超过 **1e-6 m**。这是用户指定的严格采样充分性标准；失败可能是采样漏掉最坏点对，不能自动归因于角度公式错误。
- 闭式逼近：绝对差≤**max(0.1 m, 1%×闭式 J)**。这是预设工程验收阈值，不是数学误差保证；与上一条分开判定。报告有符号差距及局部细化后的差距。
- 单调性容差 **1e-7 m**；半径与有限点云对照 **1e-6 m**。
- 兼容字段 `n_pass/n_fail/failures` 仍记录全部检查；主结论改看下述互斥 A/B/C 分档。没有以生产结果充当真值的弱对照；支撑一致性和有限候选排序都只按其狭义接口合同判定，不作为全局最优/完整后验认证。

## 数值配置及边界

固定 q 使用生产默认细级 `sample_sources(..., level=2, q=q)`；新 API 支持时显式传入案例 ε₂，旧 API 自动兼容。`SearchConfig` 仅按案例改变 ε₂；闭式另测默认点对细化。选点/曲线使用明确缩小的回归配置：站点网格 10/5 m，源网格 (3,9)/(5,17)/(9,33)，2 起点、2 对起点、2 轮点对细化、站点局部步长 5→2.5 m、边界角步长 45°、每次搜索预算 90 s。配置完整写入报告。因此选点覆盖默认算法路径，**不代表已运行默认 180 s 全域高分辨率搜索**。

独立稠密云只提供 J 下界，不能证明没找到更大点对。返回候选上的排序验证不能证明连续全局最优；本目录未提供这样的认证。已知 K 的完整 R 真值覆盖线段，三点圆枚举实现也支持非共线支撑；本轮没有独立构造完整二维曲边后验的精确 R 夹具。near 盘给出的原地结论是解析依据。

## A/B/C 分档（schema_version=2）

主分档只针对默认 J 输出；每例优先判 A，再判 B：

| 档位 | 条件 | 含义 |
|---|---|---|
| A 低估 | J_hat < 独立可达点对距离 − 1e-6 m | 真实可达反例，作为生产修复的硬回归目标 |
| B 逼近不够 | 无 A，但与闭式之差超过 max(0.1 m, 1%×闭式 J) | 数值精度不足，区别于已有反例的低估 |
| C 通过 | 适用的可达下界与闭式逼近条件都通过 | 不代表连续 J 精确，也不代替其余合同检查 |

`grade_counts` / `grade_case_ids` 为主统计；单例 `J_assessments` 保存数值、阈值、有符号差距。一个预算曲线包含多个推荐点时，以最严重档位作为案例档位。`refined_J_assessments` 和 `refined_grade_counts` 独立统计局部细化配置，不以细化通过覆盖默认失败。B 即使位于闭式真值以下，也表示**现有可达见证尚未反驳该数值**；oracle 增强后同一数值可能从 B 变成 A。

非 J 的 8 个案例（单调性 3、清除 5）不强行贴 J 档位，列于 `non_J_contract_cases` 和 `n_grade_not_applicable`。原有全部检查保持不变；`J_passing_cases_with_other_check_failures` 专门列出主档 C 但其他检查失败者。执行异常单独保留异常信息，不能算 C。

每个 A 案例的 `regression_targets`（报告顶层也有汇总）包含两个源坐标、q、共同反馈及半宽、点对距离、必须达到的最低 J_hat、两个真实世界的接收半径和距离/角误差。用独立原始距离和 atan2 再核验这些世界可实现；q=S 的共同反馈明确复用首测。未来修复后继续读取同一 `cases.jsonl` 即可保留回归目标，不能为清零 A 放宽容差或重算生产真值。

新增 15 个夹具：6 个线段解析最坏内端点（ε₂ 含 0.01°、0.03°、0.07°）、6 个极坐标窄角边界源对（ε₁ 最窄 0.0001°、镜像边界）、3 个 q=S 环形扇区闭式直径。线段最优点和极坐标边界点直接按切线角差公式构造，再向合法侧内移，并加入独立稠密点云。它们针对规则网格漏掉角约束活跃的最坏点对；绝不把该点对注入默认生产采样来消除失败。相同独立云对照仍单列检查评分实现。严格 oracle 在角界留 1e-14 rad 内缩，因此此类同云检查要求 J_hat≥独立下界，不强求与排除了阈值带点对的下界精确相等；生产见证另以共同读数的原始 atan2 误差核验，防止无依据地提高 J。三组显式反馈窗口夹具仍检验有限点云最大值相等。

原地环形扇区 5<r≤1500、|α|≤ε 的直径闭式为
`max(3000 sin ε, sqrt(1495² + 4·5·1500 sin² ε))`。
内圆开边界的角点通过 r>5 的合法点逼近，闭式是上确界而非伪造已取得的源位置。所有新增案例的 q 均允许两个见证世界实际收到第二反馈。

运行开始与结束分别记录 q2/diagnostics/feasible/geometry 的 SHA256；`production_unchanged_during_run` 用于检查并行生产修复是否让一次报告混用版本。修复后的验收方向是 A 清零、B 收敛，但 benchmark 不预先承诺当前版本已满足。

## 实跑结果

新增后共 **48 例**，最终 J 主分档为 **A=0、B=0、C=40**；其余 **8 个非 J 案例全部通过**。局部细化配置单列 **A=0、B=0、C=16**。全部检查的兼容统计为 **46 通过、2 失败**，耗时约 96.75 s，无执行异常。

两项剩余失败是 `polar_1`、`polar_6` 的 `sample_sources_nested`：q=(500,0) 和 (500,2) 的 near 补点不完全嵌套。这两个案例的 J 分档均为 C；报告独立列出它们，不能将 A 清零解释为所有合同已经通过。

生产修复已到位，本目录未修改生产代码。最终本轮运行前后被测文件 SHA256 一致性为 **True**，具体哈希见报告。指定线段闭式 15.459510178683 m，当前生产输出 15.459510178551 m。原有 11 个独立可达点对低估案例现已全部通过，新加切点/窄角案例也未产生 A 或 B。

当前没有 A，因此报告顶层 `regression_targets` 为空；所有案例的独立可达源对仍固定保存在 `cases.jsonl` 的 `ground_truth` 和报告的 `expected` 中。以后任何 A 都会自动附带完整共同反馈、两个可实现世界和必须达到的 J 下限。分档逻辑已用合成 A/B/C 数值及所有生成点对的独立可实现性核验检查过。

## 可选区间认证 oracle

`optional/certified.py` 独立计算固定 q 的连续 J 区间；`oracle.py` 将其接入
本 runner。只读取 `SourceSet` 中首测与物理常量，不调用生产的成员判据、
角事件、`parameter_point`、`sample_sources` 或 `score_point`，也不读取生产
J_hat/点对来构造界限。默认生产依赖和执行路径不变。

```bash
uv pip install --python .venv/bin/python -r algorithms/q1q2/benchmarks/q2_worst_diameter/requirements-certify.txt
.venv/bin/python -m algorithms.q1q2.benchmarks.q2_worst_diameter.run --certify --certify-tol .1
.venv/bin/python -m pytest -q algorithms/q1q2/benchmarks/q2_worst_diameter/tests/test_certified.py
```

可重复 `--case <完整case_id>` 选择案例；`--certify-seconds 60`、
`--certify-nodes 200000` 控制每例认证预算。默认另写 `report-certified.json`，
也可用 `--report <路径>` 指定；不覆盖已有普通 benchmark 报告。
连续 `score` 案例增加认证；有限点云、选点与条件 R 的原有合同检查仍保留。
这次没有增加生产 `run.py --certify`（题目中的可选项）。

后端固定为纯 Python `mpmath==1.3.0` 的 `iv`，每次调用使用独立区间上下文，
默认 30 位十进制精度，不修改全局精度。只使用区间基本四则、整数平方、
平方根、sin/cos/tan 与区间 π；依据是
[mpmath 的区间包含合同](https://mpmath.org/doc/current/contexts.html#arbitrary-precision-interval-arithmetic-iv)。
该后端的 interval 支持仍标为 experimental，本实现的证明依赖上述运算满足其
包含合同，并以独立闭式回归核验；不是形式化验证库。没有编译依赖，
Windows guest 可按单独 requirements 安装；本轮未在实际 guest 执行，
不宣称 guest 验收完成。

### 区间包含证明与边界处理

1. 输入 float 按其**精确二进制数值**解释，与生产接收到的输入一致。
   首测角盒完整覆盖 `[-eps1,eps1]`（度），用区间 π 转弧度，不从已舍入的
   `math.radians` 或生产角事件开始。对每条射线重算
   `disc=(S-c)·u squared + R²-|S-c|²`，径向端点为
   `lo=max(near,-proj-sqrt(disc))`、`hi=min(rho_hi,-proj+sqrt(disc))`。
   `r=(1-t)lo+t hi`、`t∈[0,1]` 的自然区间扩张包含所有真实径向点。
   判别式盒跨零时只将平方根输入与非负半轴相交；仅在区间证明无交时剪枝。
   无效射线的额外外包可以留下，但不能删掉有效射线。
2. 完整四维盒分别进入 near/direction 队列；q 与 S 坐标精确相同时改用
   `same_station`，直接认证 `diam(F)`。每次二分的两个闭子盒共享浮点
   分点，严格覆盖父盒。浮点物理宽度仅用于选分裂坐标，不参与证明或剪枝。
3. near 盒只有某点距离平方下端已大于 near² 才排除，上界还截到 `2*near`。
   direction 盒若某点距离平方上端 ≤ near²，或 `w` / 角度多项式上端 <0，
   可证明没有可行点；另用等价的 `tan(2eps2)w ± cross` 加强剪枝。
   未决的严格 `>near` 边界只留给上界，不给下界。点积判据无需 atan2，
   自然处理跨 0° 的共同方向圆弧，支持 `0<eps2<45°`。
4. L 来自重新区间验证的**点参数** `(alpha_x,t_x,alpha_y,t_y)`。
   径向构造证明源在圆盘/射线/接收范围内，且半径区间下端严格大于首次
   near；第二次反馈约束须整个点值区间满足（direction 使用 §6.3 原多项式）。
   距离平方根下端向下导出为 L。参数定义精确数学点，即使坐标含无理数；
   `coordinate_enclosures` 是这些点的外包，不能把其中的浮点中点冒充见证。
   开端点只用实际内移点逼近，不把上确界伪报为已取得最大值。
5. 每个活盒的距离区间上端向上导出，且可与父盒上界取 min。仅在约束
   区间证明不可行、或盒上界 ≤ 已有 L 时剪枝。U 为 `max(L,活盒最大上界)`；
   由全域覆盖不变量可得 `L≤J(q)≤U`。导出 float 时端点转换后再向外走
   一个 `nextafter`；gap 也向上舍入。这里认证的是输入模型中的固定 q，
   没有认证 C_sig 成员或外层最优 q；后验解释仍以前述保收前提为条件。
6. gap≤tol 返回 `CERTIFIED_FIXED_Q_TOL`；节点/时间预算耗尽或无法继续
   浮点二分时返回 `CERTIFIED_BOUNDS` 和真实未决 gap，不声称收敛。
   严格边界闭松弛的孤立不可达部分、退化切触、过小 tol 都可能阻碍收敛。
   若连一个实际源点也未验证，抛出 `NO_VERIFIED_SOURCE`，不把空 F 的
   未定义直径伪写成 0。API 的上下界证明不依赖有限时间收敛。

### 新增判定

逐例 `actual.certification` 报告 L、U、向上舍入的 gap、见证、节点数、
耗时、停止原因和 `converged`。顶层 `certification.verdict_counts` 独立统计：

| 判定 | 条件 |
|---|---|
| UNDERESTIMATE | J_hat < L−tol |
| OVERESTIMATE | J_hat > U+tol |
| PASS | L−tol ≤ J_hat ≤ U+tol |

预算退出也可以排除已被上下界反驳的数值；未收敛时的带内 PASS 只表示尚未
被反驳。因此 runner 另有 `certified_gap` 检查：未达 tol 会让整例检查失败，
而不是将宽带 PASS 当作精度通过。旧 A/B/C 保留其原语义，不能代替新增
三态与收敛统计。闭式例还要求 `[L,U]` 夹住保存的解析值；可选测试使用
80 位解析公式复核，包含首次开端点、第二次恰好 5 米、near、同站、
跨零、目标圆裁剪、预算退出和人为低估/高估注入。


## polar_1 / polar_6 残留复核

两例原有 grade C 正确：J_hat 分别约 995.117283、995.171633 米，独立可实现点对下界得到满足，返回见证也通过独立检查。它们不证明低估或高估；有限点云下界不能证明连续 J 的上界。

失败项仅为 `sample_sources_nested`。生产 near 圆补点每级使用 `4*grids[level][0]` 等分（默认 36、68、132），相邻级丢失 128/256 个已有点，非浮点定序误差。PLAN §7.2 与 API 表要求嵌套样本，故保留这项真实采样契约失败，不把它改成 oracle 误差或宣称全通过。report 新增 `failure_attribution` 将采样契约失败与 J 低估明确分开；所有原检查及容差保留。整体通过率与 J 分档须分别读取。
