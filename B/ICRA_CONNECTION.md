# ICRA 2013 与 B 题的联系

已完整读取Tokekar、Isler的6页会议论文，并保存[作者PDF](reference/tokekar2013asensor.pdf)、[文本与哈希](experiments/runs/2026-09-11_icra-inspiration/paper_metadata.json)。题名、ICRA 2013、2515—2520页与DOI由[明尼苏达大学出版记录](https://experts.umn.edu/en/publications/sensor-placement-and-selection-for-bearing-sensors-with-bounded-u/)核对。数学设定相近，尚无证据确认它是官方命题来源。

原文将误差表示为角锥，研究最坏位置和误差下的区域大小；区分传感器布置与选择。它的少量传感器结果需要特定几何位置及有效观测，不是任意三次测量得到精确坐标。原问题无可见性限制，主要控制静态传感器数量。[作者原文，III—VI节](https://tokekar.com/pubs/tokekar2013asensor.pdf)

对B题的迁移必须另行处理未知接收半径、180°盲区、移动/切频成本、光学清除和未知数量结束。我们已有角锥交集、舍入外包、无界处理和MEC，模型方向一致；但我们的三角格方向覆盖证书解决的是“至少发现一次”，不能冒充论文的定位精度保证。

由此增加两类独立实现：

1. [cooperative_policy.py](cooperative_policy.py)：机器人在已到达地点，为其他已发现源补几何互补的测向；在额外扫描未知频道后，以连续覆盖证书裁剪未来冗余站点。粗采样只判断一次扫描是否值得，不能负责结束证明。
2. [bracket_policy.py](bracket_policy.py)：针对B题的有限半径和180°方向，推导成对前向探测。单次no_signal不排除位置；一对合法探测都无信号后才收缩区域。该推导不是原文定理，须单独检查和评价。

成对探测的证明：以最近一次成功接收的位置s为原点、读数为x轴，真实源g=(x,y)满足x≥0、|y|≤tx，t=tan(1.02°)。选q±=(l,±tl)。若x≥l，则

$$\|q_\pm-g\|^2-\|s-g\|^2
\le l^2(1+t^2)-2lx(1-t^2)
\le l^2(-1+3t^2)<0.$$

所以两点都不比成功接收点离源更远，无需知道具体接收半径。源到s的射线穿过连接q±的线段；任何包含s的接收闭半平面至少包含一个q点。因而两点都无信号时，可安全保留半平面x≤l；保留等号与数值余量，不做过强排除。有信号则照常相交角锥，near则光学清除。有限探测预算用完仍回到已证明的光学覆盖，不能假设含噪更新每步精确二分。

原文Lemma 3还有一个可直接用于核查假设的结果：当目标在边长r的正三角形内、三个顶点的示向都有效且0<α<10°时，最坏定位直径上界为11.35r sinα。它不是“任意三个站点足够”。取工程半宽1.01°，再用平面MEC半径≤D/√3，若想仅靠这个通用界保证一次20m光学清除，边长须约不超过173m；直接把如此密的静态定位网格铺满1800m圆域会产生很大的扫描成本。我们因此迁移其“最坏区域+有用观测选择”思想，而没有照抄静态网格或把常数近似比当作B题耗时比。[作者原文Lemma 3](https://tokekar.com/pubs/tokekar2013asensor.pdf)

首轮迁移已经实际运行：六组新增9390次离线执行（其中1950次冻结后新场景确认）全部清除。确认中Q3七点联合策略普通243.96s/源、压力286.56s/源；Q4二十二点联合策略普通498.63s/源、压力619.71s/源。保留了指标退步与CPU开销：[首轮确认](experiments/runs/2026-09-11_icra-confirmation/summary.md)。没有官方成绩，也不能据此声称全面超过截图；当前240/460目标仍未达到。

后续又完成6423次训练/确认，实际补全[未知距离保收判定与连续最坏示向界](C_SIG_AND_MINIMAX.md)，并把成对探测扩展为非对称分位、把清除落点扩展为保证清除圆盘交集。后者是面向B题的独立建模，不归给ICRA论文。新冻结确认中Q4四分之一探测相对同场景快速二分版的普通/压力平均每源时间改善2.64%/6.18%，同时保留38个逐例变慢案例；连续minimax排序本身没有取得足以抵消CPU的稳定优势。[最新结果及局限](REPORT_MISSION_UPDATE.md)。

最新迁移还实际扩展了[宽成对探测的充分条件与移动上界](WIDE_PROBE_GUARANTEE.md)，实现横移限幅、面积先验和后续清除路程代理。新增5400次训练/确认全清，107—116新确认中Q4 0.15步长40m限幅较同场景quarter22普通/压力每源时间下降3.83%/3.22%，但仍有42/195局变慢，不能表述成全场景改进。Q3面积先验+路程代理仅小幅改善；扩大候选点反而整体变慢。这些属于我们针对B题的实现与推导，不是ICRA原文定理或其复现实验。[当前结果、审计和局限](REPORT_WIDE_UPDATE.md)。

后续又完成5484次任务联动、严格距离跳过、负反馈几何与加速的训练/确认。距离跳过在117—126新确认中相对对应原版，两问题各195局没有虚拟时间回退；有向服务任务规划进一步降低均值，却增加部分CPU及个例成本。利用闭圆盘/半圆盘接收集合凸性，另推导“两成功点与候选源形成的三角形不能包含真实无信号点”的排除约束，所有实际收缩案例都检查区域包含，但平均收益很小，不强行推荐。它与ICRA的有界不确定性思路相通，具体凸接收负反馈推导仍属于我们的独立工作。[当前完整证据](REPORT_COUPLED_UPDATE.md)。

最新一轮新增5343次计分全清，实际实现了一个成功点与两个历史无信号点的五半平面排除条件，并实现保留原计划的原地冗余RF删除。后者能在限定策略族上证明相对未删除版的虚拟时间/指令不增加；1152个训练/新确认配对逐动作核验，删除17219条请求，减费与实际轨迹完全相符。历史裁剪本身只有压力均值/尾部收益，普通不显著且CPU增加，保留负结果。新普通确认单批238.22/448.80秒每源达到240/460，但跨批和官方胜出尚未建立。上述负反馈/费用推导均为面向B题的独立工作，不归给ICRA原文。[最新完整证据](REPORT_HISTORY_UPDATE.md)。

最新阶段进一步把“全区域条件决定观测是否有用”落实为延后扫描移动和两个负点的无信号预测，新增8178次计分全清，其中3900次冻结后新确认。3987条配对展开核验保留原物理路径并精确复核删RF/切频减费；这是一项相对匹配无删除策略的费用结论，不是ICRA原文定理。另一方面，预测预筛与历史批处理分别在195局新确认中保持原动作不变，CPU约降低9.0%—9.6%和5.7%—8.7%。

有界区域的数学正确性仍不直接推出任务时间更低：新确认普通Q3约247.52、Q4基础预测486.38秒/源未达240/460；固定站序预测481.23更低，却有77/195局比简单距离版慢，最大压力增加1539.47秒。负反馈裁剪改变后续任务次序，可能增加扫描站数。论文引用应把原文的静态布点/最坏区域界，与我们新增的有限接收、负反馈、移动、切频和有限结束推导分开。[最新实现、数值与完整局限](REPORT_DEFERRED_UPDATE.md)。

最新阶段沿着“几何条件先于优化”的方向，实际找到了中心+8内+12外的21站连续发现覆盖。有限半径内站点的凸包判定解决任意180°源朝向，整数闭凸包判定另处理轴向相切；两规则圈的解析障碍只适用于其特定家族，不能推成全局最少站点结论。还实现了仅在公开反馈已发现16个唯一频道后，删除原地必空频道的检测。**这些覆盖、边界和计费结论均是针对B题的独立推导，不属于ICRA原文定理。**
