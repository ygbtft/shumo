# 路线算法扩展实验

基础种子 42；全部写入 B/，本地指定 Python / CPU / 单计算线程；不连接官方。

目标：实际实现免疫克隆选择、蚁群、离散粒子群、离散烟花、遗传、迭代局部搜索，加入最近邻和插入贪心基线，寻找优于旧 2-opt 的解。保留每个必需检测点，不改变覆盖/清除/结束逻辑。

1. 四个固定点集：650m 方格49点、700m裁剪方格45点、Q3三角格19点、Q4三角格31点。目标为原点出发、终点自由的总路长；原点站先访问。
2. 随机算法用相同 NN+2-opt 初解、种子 42+重复号（5次）、相同候选长度比较预算 100000（含2-opt增量比较）。完整路径计分与增量比较均计1单位；这不是相同CPU成本，另报墙钟和完整评分数。共用有限2-opt局部改进的算法明确标成混合版本。证实达到下界可提前停止。
3. 保存基线、每次运行、收敛记录及完整路线；选取每算法静态最短路线，固定后再跑在线评估。选择不读取目标真值、不用在线评估结果选路线。
4. 在同学原版 benchmark 上配对评估：Q3三角格主动、Q4三角格主动、Q4裁剪方格保守。新种子42+10+i，i=0..4；3位置×5误差=75普通场景/配置，追加边界朝外/最小半径、近共线、未知10/16源等确定性压力场景。总虚拟时间、每源时间、指令、移动、计算耗时、全清率、最坏样本和反例均记录；均值不代替保证。
5. 不以算法名字认定收益：区分静态路长改善、完整任务耗时改善与有限样本的波动。更新 B/REPORT.md，保留旧结果和原交付包。
