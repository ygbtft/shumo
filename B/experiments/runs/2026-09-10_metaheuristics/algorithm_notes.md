# 实现、预算与机制

本轮代码是适配「固定原点、自由终点、每站一次」排列问题的离散实现。群体算法均明确加入同一个有限2-opt算子，不能把它们称为原论文参数的完整复现，也不能将混合算法收益全部归功于群体机制。

| 名称 | 代码中的实际机制 | 参数 |
|---|---|---|
| 最近邻贪心 | 从原点反复选择最近未访问站点 | 稳定下标处理平局 |
| 插入贪心 | 枚举未访问点及插入位置，选最小增量，含自由终点追加 | 原点固定 |
| 2-opt | 对最近邻初解做严格下降的片段反转，含后缀 | 原有基线不改 |
| 遗传混合 | 锦标赛、顺序交叉、精英保留、反转/交换/移位变异 | 种群32，精英4，变异概率0.65 |
| 免疫混合 | 高亲和个体多克隆，低亲和个体强变异，记忆保留、重复抑制和新移民 | 24个抗体、选择前8、克隆数8−rank、强度1+floor(rank/2) |
| 蚁群混合 | 距离启发与信息素构造排列、蒸发、精英增量 | 每代20蚁，α=1、β=3、蒸发0.2、贪心概率0.2 |
| 粒子群混合 | 排列为位置，交换序列为速度；保留惯性、个体最好和群体最好方向 | 24粒子，交换保留概率0.35/0.45/0.55，随机扰动概率0.45 |
| 烟花混合 | 优者更多小半径火花、劣者较少大半径火花，高斯强度火花；保留精英及多样性 | 6烟花、基准36火花、每个2..18火花、普通强度1..6 |
| 迭代局部搜索 | 混合扰动、2-opt、等长接受、退火逃逸、停滞回到最好解 | 扰动强度随停滞增大；温度按剩余预算下降 |
| 在线贪心重排 | 每次站点扫描/清除结束后，从接受反馈中的当前位置选择最近未访问站 | 原有点集不变 |
| 在线2-opt重排 | 当前位置重建剩余站点最近邻路线，再做最多3轮2-opt，执行第一站 | 每步只使用当前位置与未访问站集 |

机制来源是[克隆选择原论文](https://www.cs.unm.edu/~forrest/classes/immuno-class/readings/DeCastro.pdf)、[Ant System原论文](https://iridia.ulb.ac.be/~mdorigo/Published_papers/All_Dorigo_papers/DorManCol1996tsmcb.pdf)、[粒子群原论文](https://staff.washington.edu/paymana/swarm/kennedy95-ijcnn.pdf)和[烟花原论文](https://doi.org/10.1007/978-3-642-13495-1_44)。本实现自行选择离散映射和参数，未调用第三方元启发式库。原论文的性能结论不外推到本题。

主实验统一最多100000次候选比较（一次完整评分或一次2-opt增量比较计1），包括算法内局部搜索；共同最近邻+2-opt初解计算不计入搜索预算，但计入墙钟时间。预算单位不是等CPU指令，不能依据比较次数直接宣称运行更快。达到已证明的长度下界即提前结束，不为了耗尽预算空转。三个点集初解已最优，随机算法这些行表示验证后提前结束，不能用来评价群体搜索优劣。Q4三角格的30次随机算法重复确实执行了搜索。

旧遗传版本是96个体×180代、仅反转变异，和本轮增强遗传版本不同。原实验「遗传未超过2-opt」只描述旧参数、旧执行；不能据此断言遗传算法都找不到更优解。本轮增强遗传明确单独记名，旧代码和历史结果仍保留。

所有候选路线先按静态路长固定，等长时保留最早种子，之后才评估完整任务。真实源数与位置只出现在生成器和评分记录中，策略没有这些输入。相同最短路长的不同排列可能使发现顺序、清除绕行与检测次数不同，因而完整任务排名可以不同。

主静态优化在后台在线评估之前完成。在线评估过程中还运行了独立的单线程消融，部分墙钟数值受同时运行任务和系统负载影响；已同时记录策略进程CPU时间，毫秒级差异不作排名依据。
