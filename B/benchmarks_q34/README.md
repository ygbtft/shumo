# Q3/Q4 独立真值 benchmark

本套件只写 `benchmarks_q34/`，不调用网络、不运行 mock 场景、不修改生产代码。遵循 `../reference/shumo-b-q12-benchmark/models/q1q2/benchmarks/README.md` 的独立真值契约。`generate.py` 和三个 `oracle_*.py` 都不导入生产模块；仅 `run.py` 导入生产实现。三个 oracle 彼此不导入，清除模块另写支持圆枚举，避免把定位 oracle 自身当作唯一正确性来源。

运行：

```bash
cd /Users/flower/math/2026/B题/B
/Users/flower/math/2026/B题/mock/.venv/bin/python -B benchmarks_q34/generate.py
/Users/flower/math/2026/B题/mock/.venv/bin/python -B benchmarks_q34/run.py
```

可用 `run.py --block coverage|localization|clearance` 单独运行，每次写独立的 `report_<block>.json`，不覆盖总报告。发现失败时退出码为 1；生成或加载错误不会被伪装成通过。

文件：

- `generate.py`：固定随机种子 3404，生成输入和独立期望。
- `oracle_coverage.py`：Fraction 几何、前缀树分区和 Q3 方块证书。
- `oracle_localization.py`：独立高精度三角函数、有理半平面交、MEC 和有限点／线段包含。
- `oracle_clearance.py`：独立支持圆枚举和 20 米三段判据。
- `cases.jsonl`：每例包含 case_id、block、category、input、ground_truth、truth_method。
- `fixtures/*.json`：冻结输入布局／证书，cases 中记录 SHA256；生产证书只是待验证的输入，不充当真值。
- `run.py`：生产适配器；不使用生产函数生成 expected。
- `report.json`：总计、每块和每类别统计、容差、所有 failures、生产文件和 cases 哈希。
- `report_results.jsonl`：保留每例实际输出，包括成功例的证书计数、区域顶点、MEC、第一动作及清除点。

## 覆盖真值

Q3 `range_area7`：针对独立构造的中心加六环站，递归生成有限 dyadic 方块。每个方块至少有一个站距全部四角严格小于 1000 米。用 Fraction 前缀树证明方块覆盖闭合 1800 米源盘；运行时再以实际传入策略的七站坐标重算每格最远距离。因此不依赖生产的环站覆盖半径公式。Q3 不需要、也不满足任意方向凸包覆盖；东侧圆周朝东的反例单独测试，避免跨问题误用。

Q4：复核 `grid21_29`（7420 叶）、`grid21_7` 和四个闭凸包相切布局。每个站点／叶角坐标直接转 Fraction，逐站逐角检查平方距离；独立构造凸包，逐边逐角检查行列式。闭式验证器要求接收距离严格小于 1000 且闭凸包包含；浮点验证器契约要求 10^-5 米接收内缩及严格凸包内缩，后者用行列式平方与边长平方比较，无开平方误差。二者不同的裕量是显式契约，不把相切证书被严格验证器拒绝当成 bug。

分区独立采用前缀树：拒绝重复、祖先／后代重叠、非 dyadic 叶；每个缺失子树必须严格位于源圆外，圆上相切格不能省略。对 `verify_cells`、`verify_integer_certificate`、`partition_check` 分别比对。生成器新产出的成功证书再交独立 oracle 复核；浮点生成器直接使用默认 `max_depth=16`，`grid21_29` 在深度 14 通过；不把 `unresolved_cell` 当作不覆盖的证明。Q3 七站仅承诺全向接收覆盖，不满足该函数要求的任意朝向凸包覆盖，增加深度不能改变这一适用范围。

对抗族含合法完整方格、凸包边界相切、严格内点、缺格、重复、覆盖根节点的重叠、非树格、负索引、共线站、超距站。适用域是闭源盘；本套件没有把 disk-only 分区说成完整根方形证书，也没有声称测试 `certify_layout_coverage` 的额外 full-square 契约。路线集合与归档坐标比对，选中策略工厂用冻结路线实例化；不运行有落盘副作用的历史布局搜索入口。

## 定位真值

用 60 位 Decimal Taylor 级数独立计算 sin/cos，量化到 35 位小数后以 Fraction 求闭半平面交。量化不是符号三角函数的形式化区间证明，但远低于记录的 2e-5 米几何容差；相切／零误差正交案例具有精确有理系数。对最终顶点的 IEEE 值另作精确 Fraction 支持圆枚举，舍入误差远小于容差。

生产契约是外包：初始 1800 米圆、每次成功接收的 1500 米上界圆均以 64 条切线外包，而不是 64 边内接多边形。本套件独立生成这些半平面，与生产区域按双向凸集 Hausdorff 距离比较，不要求重复／共线顶点数量相同。再独立检查真源包含、生产返回多边形的 MEC，而不是直径的一半。成功观测含 ±1° 端点误差及两位读数、1–4 次序列、跨 0°、零误差点／线段、近乎平行射线、1500 米距离边界和 1800 米源域边界。可行真实源坐标只在运行后评分，未送给策略。

`no_signal` 的物理真值仍按精确闭盘：Q3 合法源接收半径至少 1000，负反馈排除闭合 1000 米圆；Q4 未知朝向可在近距离背向无信号。这里的 source 是待检候选点，被负反馈排除的点不是实际世界真源。

评分采用生产承诺的**保守外包安全契约**：精确后验允许的候选必须保留，错误排除仍为 FAIL；精确后验排除的候选可以保守保留，记 PASS，并在 `conservative_extra_candidate` 和报告 findings 中单列完整性差异。独立 oracle 的 `negative_membership`、cases 和精确真值没有改动，仅新增独立安全评分规则。该规则用四种布尔组合回归验证，不能把错误剪除真源判为 PASS。生产策略和几何裕量保持原样；完整非凸后验通常不能由现有单凸多边形接口精确表示。适配器通过 `bounded_candidates` 实例化交付主候选。

## 清除真值

独立用 Fraction 枚举一点、两点直径圆、三点外接圆，仅保留覆盖所有点的支持圆并取最小半径。三段按平方量精确分类：D²≤1200（Jung 定理保证存在 20 米覆盖圆）；D²>1600（不可能）；中间必须算 MEC，不能直接按 D/2 判定。包括同直径但不同可清除性的锐角／钝角构型、点、共线重复、直角三角形、恰好 20 米及两侧、平移和固定种子随机点集。

生产没有公开的“三段判据”函数。适配器检查其 diameter/MEC 数值与三段定理相容，并真正实例化选中 Q3/Q4 工厂，在 `complete_source`／`source_packet` 的首个动作处拦截：阈值是 20−10^-5 米，不能把试探 clear 计为认证 clear。Q3 的 50 米、Q4 的 35 米试探门槛与认证门槛分开。对认证案例再测试 `closest_clearance_point`，用精确平方距离证明所有区域顶点均在该点的闭合 20 米圆内；圆盘凸性由此证明任意区域内真源均被覆盖，不依赖抽样点清除成功。

这些有限案例与覆盖证书提供可复核的独立正确性证据；不宣称证明任意输入、任意浮点尺度、全部策略控制流或整局耗时。尤其 Q3 负反馈完整后验通常非凸，现有单凸多边形数据结构只承诺保守外包，不具备精确非凸圆盘差集接口。
