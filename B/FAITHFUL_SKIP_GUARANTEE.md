# 保持原计划的静止测量删除

## 对照对象和限制

对应的原策略为关闭距离跳过的 area_return1_7、width40_f015_22，以及关闭距离跳过的加速 arc05 / locked 宽度策略。只为这些不读取实际虚拟时钟、且历史无信号仅影响已记录探测点和最近负反馈冷却的策略证明；不自动推广到依赖实时时间、额外负反馈裁剪或随机请求序号的任意算法。比较要求同一题设合法静态场景、同地点同频道误差固定、协议行为一致，并在两策略真实运行预算都足够时进行。

## 删除规则

已发现且未清除的频道 ch，当前正在保证扫描；保守可行区域包含于 MEC(c,R)。若 ||q-c|| > 1500+R+10^-5，则任意可行源 g 到 q 的距离严格超过最大接收半径，不论定向朝向都必为无信号。

进一步要求 q 与客户端实际位置逐坐标完全相同。协议把移动和测量合并，故到新点的首条测量保留，不能在没有移动指令的情况下伪改位置。删除时只更新内部“计划频道”、计划曾检测位置与负反馈冷却记忆，明确返回推断标记 certified_no_reception；不写入射频反馈记录、不改变客户端频道/位置/虚拟时间、不发伪请求。计划频道决定下次扫描排序；客户端频道仍由实际请求决定并计费。

## 计划等价的归纳

初态相同。归纳假设原策略与新策略的当前实际位置、可行区域、测向记录、已清除频道、计划中已尝试位置、冷却记忆、累计探测/打断预算和任务列表一致，并且新策略的计划频道等于原策略实际频道。

若下一次动作不删除，两策略选择同一位置、频道和动作。接收/光学结果与固定测角只取决于场景、位置、频道和是否已清除，因此有相同的决策反馈；网络请求编号和时间戳无需相同。若是待删除动作，证书证明原策略反馈必为 no_signal；原策略在该静止 RF 后没有区域更新或共享探测，仅记录尝试位置和冷却，新策略同步这两项内部事实，二者实际位置仍相同。计划频道在每次测量入口先更新，以保留嵌套共享测量的最终频道。任务排序不读实际频道（扫描排序使用计划频道），不读实时时钟，所以归纳继续成立。

因此展开包含被删逻辑操作后的计划与原策略逐动作等价；所有保留的移动、光学清除和成功示向相同，且停止依据相同。原策略的覆盖、全清和有限结束保证得以继承，原335136s/9766条粗上界仍适用。

## 时间和指令支配

删除 n 条原地 RF 恰好减少 n 条请求和 5n 秒检测费用。所有移动段保持相同（删掉的段长为0），所有光学费用相同。实际测量频道序列是原序列的子序列，频道切换成本 d(a,b)=1[a≠b] 满足三角不等式，包括初始频道1；故切换次数不增加。于是 T_new ≤ T_reference −5n，指令数恰好少 n（均包括同样的 enter/exit）。各移动时间逐段相同，微秒舍入也相同。

该结论是相对明确原策略的虚拟时间/请求数支配，不是任意场景都严格改善，不是相对旧 range_skip 策略的支配，也不保证真实 CPU 更低。没有可删请求时新增几何检查可能只增加计算。实验还必须核对展开计划、原地条件、客户端未伪改、真实源保留、频道切换费用和关闭功能的等价性。
