# 任意历史成对无信号的排除约束

已成功接收点s、同一源清除前的实际无信号点q1,q2均为公开记录。若某候选源位置g同时满足：

1. ||q1-g||≤||s-g||且||q2-g||≤||s-g||；
2. 线段[s,g]与[q1,q2]相交；

则g不可能是真实源。第一项说明两个负点都在未知接收半径内，因为s曾成功。对于全向源已直接矛盾；对于定向源，接收闭半平面包含s和g，必包含[s,g]及其与[q1,q2]的交点，所以q1、q2至少一个属于该半平面，也应能接收，矛盾。

这比“两个负点都在最小接收圆内”的条件更通用，又保留了不可缺少的距离判定。仅因线段相交就排除位置是错误的：先前45度宽探测反例中一负点超过真实接收半径，必须保留。

非共线时，令r1=q1-s、r2=q2-s，以逆时针夹角小于180度排序。线段相交条件可表示为g在s出发的r1/r2角锥内，且位于q1q2直线与s相反的一侧，共三条线性半平面。距离条件展开为

    -r_i·(g-s) ≤ -||r_i||²/2, i=1,2。

因此排除集合E是五个半平面的交。实现把P裁剪到五个补半平面并集，再取凸包，得到P\E的保守凸外包，不声称完整精确可行域。所有约束归一化，补集边界外移0.0001m；近共线生成射线跳过，小到浮点噪声级别的改变保留原P；空裁剪记录不一致并保留旧区域。

每源保留最近4—16个实际负点，成功锚点取首次、最近或两端，构成固定规模子集。推断仍可在仅一次有效示向后生效，不新增射频请求，不使用目标真值。距离证书跳过的请求本轮不混入实测负记录。源清除后的无信号不能参与约束，频道唯一且静态是适用前提。

该过程只收缩已有角误差外包区域，仍使用1.01度处理±1度及返回舍入。主动/光学预算与覆盖/未知数量停止条件保持原样，所有动作位置范围不扩大，仍适用335136s与9766指令的宽松界。有限样本通过不替代此条件性证明；数值实现另需独立线段/距离判定、完整协议及逐次区域包含审计。
