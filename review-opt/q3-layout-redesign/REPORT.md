# Q3 覆盖布局重设计：巡回可缩短，150 s/源仍未达到

结论：已找到比原七站 6840m 巡回更短的合法覆盖路径，因此本轮不支持原巡回已经近最优的结论。69 套新整数布局通过完整证书；其中一条 33 站开路径仅 5434.49m（缩短 20.55%），但闭环 τ 反而明显增大。七站微调在第一组验证约改善 0.57%，第二组独立验证未复现；不建议替换主候选。不能据此证明所有合法布局都无法达到 150。

## 1. 约束、接口与证书口径

本轮仅 Q3。源域是 modeling-q34.md 明示的 D(0,1800)，接收半径固定按 1000m。完整根方形分区的含义是 [-1800,1800]² 的全部叶格都显式保存、互不重叠且没有缺块：接收叶由一个站的 1000−10⁻⁵m 盘覆盖；域外叶必须整数精确证明与源圆盘不相交。**不声称源圆之外整个方形也被接收盘覆盖。**

原 integer_visibility_certificate.py 仅提供 Q4 凸包接口，visibility_certificate.certify_layout_coverage 还强制 problem=4 及全方形覆盖，不能冒用作 Q3 证书。故只新增 certify_integer_omni_stations / verify_integer_omni_certificate 与 verify_omni_cells；原 Q4 凸包判据、原入口及 icra_final_checks.partition_check 一字未改。Q3 入口独立绑定 problem=3、坐标集合与实际路线，调用原 partition_check 并以精确有理数检查总叶面积=3600²。

权威生成器用尺度 2¹⁶ 的整数平方距离；独立复核器逐角用 Python 无界整数重算，并从完整根节点遍历每个子格。浮点复核器独立重算四角距离并保持相同 10⁻⁵m 内缩余量。所有候选先出证，再进入 mock；9 个失败布局另有毫米整数坐标的盲区反例，完全不进入评分。当前浮点原布局保留原解析覆盖依据和原坐标作为基线，不把它的取整近似冒充默认基线。

## 2. 搜索方法与覆盖边界

目标为 L=|s₁|+Σ|sᵢ₊₁−sᵢ|，无需回原点；站数不作目标。先搜索 6、7、8、9、10、11、12、14、16、20、24、32 个外站的等角环和不同半径、不同角间隔的非对称布局。几何搜索独立于任何源真值，SLSQP 多起点记录见 search_all.json；边界弧约束用于筛选，绝不替代内域证书。随后根据训练结果补测原点是否扫描、半径和旋转角；这一阶段仍只用原训练种子。

对半径 r 的站，能覆盖的源圆周半角 α(r)=acos((1800²+r²−ρ²)/(3600r))。相邻角差不超过 αᵢ+αᵢ₊₁ 可覆盖边界，但可能留下内部空洞；本轮若干六站反例正说明这一点。整数化之前设计半径用 998m 或 999m 留取整余量，最终证书统一仍为 1000−10⁻⁵m。

不论站在哪里，一个站在源圆周上最多覆盖 2 asin(1000/1800)≈67.50°，所以至多五个站不可能覆盖源圆周。这个下界只证明至少六个有用外缘站，不证明六站可行、七站最优或原布局近最优。

原点固定且外站≤16时，用 Held–Karp 求固定坐标集合的最短开路径；这只证明访问这些点的排列最优。更大布局报告已构造路径上界，不称其为 TSP 最优。全局布局最优没有证明。通用管状邻域面积界给出 L≥π(1800²−1000²)/(2×1000)=3518.58m，与已构造 5434.49m 之间仍有大缺口，不能拿局部搜索失败作不可达证明。

## 4. 发现→定位→清除的闭环依据

覆盖证书保证任意源至少有一个必经接收站。对尚未发现的频道，继承的循环在每个站执行真实 RF；距离跳扫和“已精确”跳扫只作用于已经发现的源。除公开16源上限已全部发现/清除外，不能跳过剩余发现义务；结束时要求所有站完成且全部已发现源已清除。因此不会把较少扫描当作排尽证明。

定位和服务算法完全沿用当前 OmniNegativeCompletionPolicy。1.01°半宽、20m清除判据、保守区域、最多3次主要主动测量和有限光学覆盖兜底均未放宽。未获几何保证的50m试探允许正常 no_target_in_range，随后继续测向或有限光学清除；试探失败不冒充成功，也不作为异常结束。此为模型与循环层面的排尽依据，浮点实现仍以独立包含性检查和实际协议回放复核，不将有限 mock 样本宣称为数值实现的全空间形式化证明。

共 **48300 次执行全部全清，异常0、位置区域丢失真源0**；检查 1899620 次区域更新。主验证、补充验证和压力验证的全部 18480 份轨迹逐动作重新核对，涉及 3338492 条动作记录，240240 次成功清除、51766 次合法清除失手。最大成功清除距离 19.999986119m，小于20m；最大实际示向误差 1.010000000000°，没有扩大1.01°界。

压力场景包括严格1800m边界、候选站角间隙方向、共线源、远端密集/近重合源、原点与边界混合；全部ρ=1000。额外压力把本地误差场设为±1.005°再按原mock最近0.01°舍入，令总误差达到但不超过原1.01°外包；这比物理±1°压力更强，并未修改模拟器或算法角界。

另外完成 57 次逐请求反馈回放（各候选最坏回退、最大收益、最多失手等），只把原反馈交给策略；完整运行之后才读真值检查区域。回放绑定原会话随机 request_id 前缀，坐标、频道、动作、顺序和其余请求字段逐项完全一致。详见 [audit.json](audit.json)。
