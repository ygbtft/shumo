## 4. 新预算界：解析有效，但浮点临界值不可作严格认证

### 4.1 推导复核

令两个源为 `(a,0)`、`(b,0)`，`0≤B<a<b`，站点为 `(t,z)`、`r²=t²+z²≤B²`。点积至少为 `(a-r)(b-r)>0`，故夹角在 `[0,π/2)`，且

\[
\tan\psi=\frac{(b-a)|z|}{ab-(a+b)t+r^2}.
\]

对固定 r 求导得到极大点 `t=(a+b)r²/(ab+r²)`；其满足 `|t|≤r`。代入后得到

\[
\tan\psi_{\max}(r)=\frac{r(b-a)}{\sqrt{(a^2-r^2)(b^2-r^2)}}.
\]

该式随 r 递增，最大值在 `r=B`。因此提交的新解析公式正确。旧 `asin(B/a)+asin(B/b)` 由两个方向偏转之和给出上界，新式是全预算圆盘的实际最大角，自然不劣于旧界。`B=0`、两源趋近、`B→a⁻` 不构成推导反例；`a=b` 被该 API 的严格输入域排除。

非共线推广用圆周短弧距离的三角不等式：初始夹角 γ 加两个 `asin` 偏转上界。成员条件确保两个源首测相容；`B<min(r_x,r_y)-5` 确保预算内不会进入 near；在保收站点，两源各有合法世界并允许共同 direction，故给出其欧氏距离下界。同站按保留原源集处理。它是给定源对的充分条件，没有证明最优源对包络。

独立脚本 [audit_budget.py](verify-q12-data/audit_budget.py) 使用 100 位算术，通过极值站点的两个实际方位角复算 1005 组标准、随机与退化输入，并比较旧角界。未发现解析新界大于旧界。另对五组非共线源对各取 4096 个圆周站点检查，均满足给定角上界；近场等号、非法源、相同源、相同半径、非法预算亦单独检查。有限采样只是补充，推导是全圆盘结论的依据。全部数值见 [budget-independent.json](verify-q12-data/budget-independent.json)。

### 4.3 已发现的临界舍入问题

提交精确 binary64 输入 `B=26.15075608573123`（`0x1.a2697f369e37cp+4`），当前 `tight_short_baseline_lower_bound(ss,500,1500,B)` 返回 `angle_bound_deg=2.0`、`lower_bound_m=1000`。

但 100 位区间运算证明真实最大角 **严格大于 2°**：

`2.000000000000000001931772677041694718526090626390163151275383320344…°`。

极值站点约为 `(1.82197081470084245,26.08720886192670824)`。复现输入、返回值和区间包络见 [budget-threshold-counterexample.json](verify-q12-data/budget-threshold-counterexample.json)。这证明该浮点分支会误判解析角条件；并不单凭这一源对证明真实 V(B) 已小于 1000 m。

此外，`B` 极接近 `a`、`b` 又接近 `a` 的压力输入中，122/1005 例与高精度值的绝对差超过 `1e-7°`，最大约 `2.56094e-5°`。例如 `a=52.96035024800184,b=52.96493322961901,B=52.96035024794888`，生产值 `89.98768147860378°` 小于真实值 `89.98768176105555…°`；因此独立角函数的数值返回值也不是单侧上界。此类 `B≈a` 例违反标准 near=5 下的严格预算条件，会被下界包装函数挡住。

改动说明已经承认 binary64 非认证属性，因此这不是其“留裕度到26.15米”结论的反证；但必须保留这个具体数值限制。若以后需要严格自动判定，应使用向外舍入角上界或经证明的保守裕度，不应仅比较普通浮点数 `angle<=2*half_width`。

### 5.1 域与全部闭叶

标准模型下，C_sig 的四圆盘表达与其径向约束相容：近端取 r→5 的极限，r≤1000 由端点盘和凸性控制，r≥1000 的约束由 r=1000 的条件控制。远端两盘推出 qx≥0，近端盘给出 qx≤1005、|qy|≤1000；关于 y 的反射保持源域、共同反馈和同站目标不变。因此覆盖 `[0,1005]×[0,1000]` 加反射足以覆盖整个 C_sig。这一步限于提交的标准对称模型。

逐叶复算结果为 **5319 个处理节点、2660 个闭叶：862 个 disk、1798 个 pair、0 个 pending**；归档与从零生成结果相同。

* **圆盘排除：**用独立 100 位区间计算真实三角圆心，再将区间端点无损转 Fraction；计算整个叶盒到圆心包围矩形的最小距离平方，要求严格大于 1000000。862 个全部通过，最小严格余量约 **0.1725784777 m²**。没有拿盒中心距离替代全盒距离。另测包含原点而中心远在候选域外的 `[0,2000]²`，生产排除器正确拒绝圆盘剪枝。
* **源对下界：**源坐标按 exact binary64 转 Fraction，独立展开点积及 `k*w±cross`；枚举矩形角点、边界驻点、内部驻点取精确最小值。1798 个全部满足三个非负条件、源对长度平方≥target²、两源到全盒的最小距离平方严格>25。最小源对长度平方余量约 **0.0042352022 m²**，两个角多项式的全局最小余量分别约 **12.64727410** 与 **0.0008830525892**。
* **源成员：**所有 **866 个不同实际源点**通过 100 位区间检查：严格 r>5、闭 r≤1500、两条闭角界；目标圆半径1800包含整个源域。近端5米极限圆心没有混作合法源见证。亦独立证明有理 `k=5032613263056833/144115188075855872` 严格小于 tan(2°)。
* **覆盖：**自己实现横向薄片检查，与提交检查器的纵向扫线不同。**696 个水平薄片**上的 x 区间都无缺口、无正面积重叠，总面积精确为 **1005000 m²**；有限闭盒也覆盖薄片边界。这里的696与其自报650个 x薄片不是矛盾，扫描方向不同。

每个叶的精确余量保存在 [归档逐叶结果](verify-q12-data/outer-archived-leaf-checks.json)、[新证书逐叶结果](verify-q12-data/outer-fresh-leaf-checks.json)，摘要见 [outer-independent.json](verify-q12-data/outer-independent.json)。

### 5.2 incumbent 及向外舍入上界

\[
