# 同射线预算 API 临界舍入修复与论文补丁说明

2026-09-12。针对 `verify-q12.md` §1 第4行、§4.3；本次没有修改 `models/paper-full.md`，没有访问官方模拟器或触发正式测试。

## 定位与修复

`models/q1q2/q2.py` 中 `tight_short_baseline_lower_bound` 原先调用普通 binary64 的 `same_ray_max_angle_deg`，直接比较 `angle <= 2*half_width_deg`。审计输入的真实最大角严格超过 2°，却被舍入为 2°并触发 1000 m 下界。

现在默认 `same_ray_max_angle_deg` 返回向外舍入上界：用独立的 50 位 `mpmath.iv` 上下文按原解析公式计算，包括区间平方根、atan2 和 π；取区间右端点转 binary64，再向正无穷移动一格。区间包含真实角，右端点转换最多舍入到相邻 binary64，向上移动一格后必不小于右端点。因此通过比较时真实角一定不超过阈值；阈值在输入范围 `[0,90]` 内乘2精确，无额外阈值向上舍入。零预算直接返回数学上精确的零，保留零半宽情形。临界不确定时允许漏报。

原快速算法保留为 `same_ray_max_angle_estimate_deg`，明确标注非认证，默认下界接口不使用它。运行依赖增加 `mpmath>=1.3.0`，缺失依赖时不会静默回退到浮点估计。保证依赖 `mpmath.iv` 的区间包含合同；不是形式化证明系统。输入语义为精确 binary64 径向参数和角度。源成员检查、near 排除和返回距离沿用原语义，本次没有将整个几何链条宣称为新认证器。旧 `short_baseline_lower_bound` 与非共线 `source_pair_budget_lower_bound` 未改动。

## 给父 agent 的论文文字

保留解析公式、原命题和原证明。**“移动预算为10米时，最坏剩余歧义仍至少为1000米”及“预算不超过26.15米时，仍至少保留1000米最坏歧义”均原样保留。** 旧临界约 `13.088806351423712` m、新临界约 `26.150756085731231312` m 的数学结果不变。

建议将 `q12-production-paper-patch.md` §3 中关于 G3 “生产计算使用 binary64；不是向外舍入区间证书”的旧实现说明更新为：

> 同射线最大夹角的解析表达式保持不变。自动角条件判定采用区间运算及向外舍入所得的上界，仅当该上界不超过两倍反馈角半宽时才触发下界；未能通过此充分条件不表示已能定位。快速浮点估计另设接口，不用于严格角条件判定。输入按其实际 binary64 值解释，保证依赖区间运算的包含合同；实际源成员与其余几何前置条件仍沿用既有检查。论文的保证预算继续采用26.15米，不以舍入显示的临界小数代替严格判定。

该更新仅指同射线角条件，不扩张为非共线接口或完整几何链条的认证声明。

## 临界行为对照

`float('26.150756085731231312')` 就是审计的 `0x1.a2697f369e37cp+4`。其真实角度的100位独立区间下端严格大于2°。

| 实际 binary64 预算 / m | 改前角估计 / ° | 改前触发 | 改后角上界 / ° | 改后触发 |
|---|---:|---|---:|---|
| 10 | 0.7640682458261854 | 是 | 0.7640682458261855 | 是 |
| 26.15 | 1.9999420457645092 | 是 | 1.9999420457645092 | 是 |
| 26.150756085730233（约临界减1e-12） | 1.9999999999999234 | 是 | 1.9999999999999236 | 是 |
| 26.150756085731228（相邻较小浮点数） | 1.9999999999999996 | 是 | 1.9999999999999998 | 是 |
| 26.15075608573123（审计反例） | 2.0 | 是，误触发 | 2.0000000000000004 | 否 |
| 26.150756085731235（相邻较大浮点数） | 2.0000000000000004 | 否 | 2.0000000000000004 | 否 |
| 26.15075608573223（约临界加1e-12） | 2.0000000000000764 | 否 | 2.000000000000077 | 否 |

表中所有“是”对应至少1000 m；“否”只表示此充分条件未触发。完整100位独立极值站点方位角区间、浮点十六进制输入和返回值见 [threshold-comparison.json](q12-budget-rounding/threshold-comparison.json)。改前触发列使用保留的原浮点算法重现原角分支，表中所有输入均满足未变的几何前置条件。
