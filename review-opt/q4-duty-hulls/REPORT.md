# Q4 固定检测职责：安全迁移、累计免走及合并不可行证据

2026-09-12。本轮只做本地 mock，基线为冻结的 `range_grid21_29`。**结论：三个实验候选均否决，不替换默认。** 安全迁移在验证中 Δτ=-0.077063 秒/源，未形成结构性收益；累计补扫 Δτ=+8.463377，不能抵偿补扫成本。主要新增结果是一个可独立复核的否定结论：**保留其余 19 个原站时，任意两站的全部任意朝向检测职责都不能合并到一个新位置，210/210 对均有精确证据。**

所有文件位于本目录。没有修改生产工厂、主候选默认、±1.01° 包络、20 米真实清除判据；没有访问官方模拟器、触发正式测试或使用任何内存恢复数据。保留已确证的固定站集合 MST=17294.76 m 及混合场约 290 秒/源下界，不将其误说成任何新布局的普适下界。以下全部均值是 `Σ整局虚拟秒/Σ真实源数`，没有取逐局均值，也没有按真值挑更快策略计分。

## 方案与执行顺序

先检查原负反馈能否安全免走，再从任意方向覆盖的凸包条件推导替代点可行区域；最后探索多个路过位置累计承担剩余职责。新接收点只有在真实测量后才能激活。切频重排作为独立对照，避免将它混入移动收益。历史清除点“一次补扫立即替代一站”原型已有，本次不同之处是显式求替代点的凸可行区域，以及允许多个新位置先累计职责、完整证书成立后再删站。

## 1. 安全免走的充分条件

令 D 为原问题半径 1800 米的源圆盘，接收最小半径仍取 1000 米。对未发现频道 c，令 N_c 为真实接受的 `no_signal` 位置集合，U_c 为仍承诺完成的未来测量点。若对覆盖 D 的每个封闭方格 Q，存在有限集合 E_Q ⊆ N_c∪U_c，使得：

1. E_Q 每点到 Q 四个角的距离都严格小于 1000 米；
2. Q 的四个角都在 conv(E_Q) 内；

则未来履行 U_c 后，不可能仍有该频道的未发现源。距离的凸性使 E_Q 对整个 Q 均在接收范围内；凸包包含使任何经过源点的闭半平面至少包含一个 E_Q 点，因此任何 180° 朝向至少接收到一个点。全向源自然也被覆盖。全部测量阴性与源存在矛盾。

**免走 i 的充分条件**：删除 i 后上述逐格条件仍成立。已完成的测量只能贡献其实际频道的证据。实现为了审计简单，对新点扫描所有当时未知频道，因而所有最终未知频道共享同一个实际阴性点集合；已发现频道保留原定位和有限清除流程。这是频道级充分条件的保守实现，没有声称利用了不同空频道之间的统计相关性。

运行中的不变式为“已真实扫过的新旧点 + 尚未履行的原站”覆盖全域。补扫完成后添加点，再逐个删除通过证书的原站；迁移也是先验证替代几何、真实扫完再转移职责。停止时逐频道核对所有活跃点确有真实 `no_signal`，且已发现源全部清除；公开上限 16 的原停止条件保留。拒绝、推断跳扫、其他频道负反馈都不能充当该频道阴性。

`hull_geometry.py` 从本次冻结坐标重新生成 7420 叶的连续方格证书。每次候选转移都用整数最远角距离和整数凸包边支撑逐格验收；正几何余量至少采用保守的 10⁻⁴ 米阈值。实际新停靠坐标取整数，所有中间积保持在原整数检查器的 int64 安全范围。最终每个候选运行都另过：

- `visibility_certificate.verify_cells`：连续方格的独立严格凸包检查；
- `integer_visibility_certificate.verify_integer_certificate`：Python 无界整数四角三角形与分割检查；
- `icra_final_checks.partition_check`：检查缺格、重叠和被省略的圆盘外格。

这些接口验证的是**原源圆盘**。`verify_cells` 返回的 `coverage_guarantee:false` 表示它本身不宣称覆盖整个 [-1800,1800]² 方形；本轮没有扩大源域或冒称整方形覆盖，实际坐标、Q4 问题类型和全部活跃点的频道阴性账本由实验协议另行绑定。原圆盘覆盖义务没有削弱。

初版 pilot 曾只接受闭凸包，独立严格浮点检查拒绝了贴方格边界的迁移；该 pilot 已中止并保留目录，未计入性能结论。随后将在线验收加强为上述严格余量，`pilot2` 的 28 次运行及后续训练/验证全部通过三项检查。原始整数闭凸包证书依然合法，此处选择更保守的验收以同时满足两套接口。

## 2. 为什么直接删站、两站合一被否决

### 原站负信息不足以删任意一站

对每个原站 i，均找到一个位于 D 内、半径 1000 米的合法定向源，仅 i 能接收，其余 20 站都无信号。这类源与“其他原站上全阴性”的记录完全兼容。因此，当未发现频道仍可能存在且未达到公开 16 源上限时，仅有其他原站的阴性不能排除 i 的职责。已定位或已清除其他频道，不会自动产生该未知频道的朝向信息。

### 两站合一的精确必要约束

对 i 的任一个独占反例 (g,v)，v 为整数朝向法向量。若新点 q 替代 i 的全部检测职责，它必须接收该反例，因此必须满足 vᵀq≥vᵀg，另有 ||q−g||≤1000。这里甚至只使用前者，不需要接收圆约束。

用非负有理数线性组合，将有限个必要半平面变为 q_x、−q_x、q_y、−q_y 的四个坐标上界。独占性由 Python 整数距离平方、整数点积检查；线性组合等式和系数非负性用 Fraction 精确复核。每一对 i,j 至少有一个坐标方向的必要区间严格分离，故同一个 q 不可能同时接收两者的所有独占反例。

例如站 1=(706,706) 的必要约束给出 q_x≤34250/39≈878.205；站 2=(999,0) 给出 q_x≥6450/7≈921.429，至少相隔 **43.223443 米**。其余各对也有正间隔。完整证明共有 84 个坐标界、117 个反例项，排除 210 对；证据来自合法问题几何，不是读取任何场景真值。

证据文件：[pair-merge-dual-proof.json](pair-merge-dual-proof.json)；独立检查结果：[pair-merge-dual-checks.json](pair-merge-dual-checks.json)；验证器：[dual_merge_proof.py](dual_merge_proof.py)。扫描网格仅用于**寻找反例**，有限精确反例本身就足以证明不可行，并未把网格无漏检当作覆盖证明。

**结论边界**：证明排除了“其他原站固定，删两站添一站”；不证明任意 20 点布局都不存在，也不排除多个新位置共同重新分担职责。累计补扫原型正是在尝试后一条路。

## 3. 三个原型及否决原因

**`duty_flex`：安全迁移停靠点。** 去掉原站 i，计算其他可接收站在每个缺覆盖角点处的两个切向边界。新点必须落在相反的方向扇区，同时接收全部相关方格；其可行集合是半平面和圆盘的交。SLSQP 只提出当前点→新点→预计后继的较短路径；取整后必须通过上述完整整数证书，且预计少走超过 5 米才执行。其预测不参与清除或排尽证明。

验证实际迁移 281 次，删除原扫描任务 0 个，空频道 RF 不降。覆盖约束允许的有益位移很小，而且测向点变化会改变后续定位和调度，所以局部路段节省不保证整局占优。**否决：均值收益太小，且存在逐局回退。** 不把它包装成突破 MST 主项。

**`duty_accumulate`：累计路过点补扫。** 在完整原子定位 packet 结束后考虑当前坐标附近的整数点；若能立即替代未来站，或补足某近邻站当前缺失角点职责的面积权重至少 60%，就扫描所有未知频道。每局最多补 4 次，已发现频道数达到 14 后停止新补扫。面积比例只用于决定是否花费测量，永不授权删站；实际删除必须逐格全证书成立。原有成对探测保持原子性，±1.01°、20 米清除条件不变。

验证补扫 833 次、补扫 RF 9762 次，仅成功删除 0 个原站。新增信息也改变发现次序，可能推迟达到 16 源提前停止，造成长尾行程。**否决：补扫费用和路径扰动超过少量免走收益。** 所有成功删站局另外逐事件反馈重放，完整中间证书见 `certificates/` 与 [deletion-replays.json](deletion-replays.json)。

**`batch_tail`：已知频道置尾。** 保留当前位置的当前频道先测，把一个最近的未清已知频道放到扫描末尾，尝试让随后的源 packet 少一次切频。没有减少测量或更改停靠点。训练与验证均增加切频；末尾频道可能先被清除，反而破坏下一站复用频道的机会。**否决：没有移动收益，切频也未改善。** 未重做历史的“把测量费加进路线评分”参数扫。
