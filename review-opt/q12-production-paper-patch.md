## 1. 建议在原短基线命题之后新增，不替换原判据

保留原句：“移动预算为10米时，最坏剩余歧义仍至少为1000米。”原 `short_baseline_lower_bound` 的代码、返回字段与数值均保持原样。

**建议新增正文：**

> 对同射线候选源还可加强上述角度估计。设两源为 $x=S+au$、$y=S+bu$，其中 $0\le B<a<b$。在整个移动圆盘 $\|q-S\|\le B$ 上，两条视线的最大夹角为
> \[
> \Psi_{a,b}(B)=\arctan\frac{B(b-a)}{\sqrt{(a^2-B^2)(b^2-B^2)}}.
> \]
> 因此，当两源均属于首测实际可行集、$B<a-5$ 且 $\Psi_{a,b}(B)\le2\varepsilon_2$ 时，对预算内任一保收第二测点，最坏后验直径仍至少为 $b-a$。该式给出固定源对在整个预算圆盘上的精确最大夹角；加入保收或行动域约束只会缩小可选站点集合，不影响上述下界。取 $a=500$ 米、$b=1500$ 米、$\varepsilon_2=1^\circ$，预算为10米时夹角上界从原来的 $1.527967^\circ$ 降至 $0.764068^\circ$；预算不超过26.15米时，仍至少保留1000米最坏歧义。

**证明可补入附录：** 平移旋转令 $S=0,u=(1,0)$，记 $q=(t,z)$、$r^2=t^2+z^2$。两视线点积为 $ab-(a+b)t+r^2>0$，故
$\tan\psi=(b-a)|z|/[ab-(a+b)t+r^2]$。固定 $r$，极大点满足 $t=(a+b)r^2/(ab+r^2)$；代入后关于 $r$ 单调递增，取 $r=B$ 即得公式。此角度不超过原来的两个偏转角之和，故同一源对的新充分条件不劣于旧条件。

生产入口：`same_ray_max_angle_deg` 与 `tight_short_baseline_lower_bound`。前者返回度数，后者独立于旧 API 给出新增的解析下界。

## 2. 随后新增非共线推广

**建议正文：**

> 上述不可辨识论证也适用于非共线源对。设 $x,y$ 均属于首测实际可行集，$r_x=\|x-S\|$、$r_y=\|y-S\|$，初始夹角为 $\gamma$。若
> \[
> 0\le B<\min(r_x,r_y)-5,\qquad
> \gamma+\arcsin(B/r_x)+\arcsin(B/r_y)\le2\varepsilon_2,
> \]
> 则预算内任一保收第二测点仍有 $J(q)\ge\|x-y\|$。证明只需将初始夹角加入移动造成的两个方向偏转上界，再由圆周角距离的三角不等式得到共同反馈；严格距离条件排除了近场反馈，原站点则保留首测已相容的两个源位置。

生产入口为 `source_pair_budget_lower_bound(ss, x, y, budget_m, half_width_deg)`。它核验实际源成员资格和严格 near 条件，只检查调用方给定的一对源；没有实现遍历全部连续源对的最优下界包络。这个推广不保证比同射线构造产生更大的距离下界。

**统一的诚实边界：**

- 这些都是保收策略类内的充分条件，不是 $V(B)$ 的精确解。跨过26.150756米不意味着可以完成定位，也不是最小必要基线的精确值。
- G3 的解析公式精确，生产计算使用 binary64；它不是向外舍入的区间证书。端点临界值不宜按显示小数直接作严格认证。生产沿用实际浮点源成员检查；没有宣称完整链条获得形式化认证。
- “同射线预算下界的加强”“非共线推广的充分条件”是合适措辞；没有做文献首创性证明。多次自适应测量的推广未作为本次 API 实现。

## 3. 工程段可替换或追加的措辞

> 在保持原几何判定合同的前提下，程序采用四项局部优化。方向接触补样在单次调用内缓存精确坐标对应的合法点构造结果，包括失败结果；半平面交点使用整数齐次坐标，在完整成员检验通过后才构造约分有理数；二进制点云的平方距离通过共同二进制分母转为整数比较；最小覆盖圆的临时圆仅用于提议支撑，最终仍在原始坐标上进行精确包含、支撑凸包和输出可表示性检查。不可靠的提议进入原精确回退。半平面交点枚举仍为 $O(M^3)$ 算术操作，未改变其复杂度阶。

具体不变量：缓存键严格为 `tuple(x)`，未四舍五入，没有全局缓存或跨 ss/q/角宽/inward 复用；所有 deadline 检查仍在原位置。行清分母及 gcd 均采用正因子；交点分母变号时同步变号两个分子。非二进制分母 Fraction 坐标沿用精确有理数距离路径，不先转 float。最远点对仍按原 i/j 顺序及严格 `>` 更新，保留并列索引规则。对外 `forced_circle` 不变，钝角三点的内部提议仍为强制外接圆。
