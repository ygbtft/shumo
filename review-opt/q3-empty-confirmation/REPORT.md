## 1. 当前到底测了什么

`bounded_candidates.build` 的 Q3 工厂是 `OmniNegativeCompletionPolicy`。其扫描循环对未清除频道测量；已知频道可以使用原有精确区域或最大接收半径免测，但**未发现频道没有区域，因此每个实际扫描站都获得真实 RF**。定位共享 `share_at` 只遍历已知 `regions`，不会免费探测未知频道。

`no_signal` 只有针对本次请求的频道才有效。车经过某点、测过其他频道、或清除了其他源，都不能算作本频道的接收观测。已知源的距离优势半平面需要同频道成功锚点；空频道没有成功锚点，不能套用。

公开“最多 16 源”只在已发现 16 个不同频道时可以结束发现；这是基线已有逻辑。对于已发现 10–15 源，仍允许另一个未知频道存在源，不能从 mock 实际 n 推出停搜。

## 2. 可复核的充分条件

令源域 `A={g: ||g||≤1800}`；`N_c` 是频道 c 在清除前、被协议接受的真实 `no_signal` 测点集合。Q3 全向接收且 `ρ_c≥1000`，因此若 c 有源，必满足

\[
\forall q\in N_c:\quad \|g_c-q\|>\rho_c\ge1000.
\]

只用这些负观测时，其位置可行域恰为

\[
F_c=A\setminus\bigcup_{q\in N_c}\overline B(q,1000).
\]

“恰为”针对单频道负观测的位置投影：每个盘外位置都可选合法半径 1000 与所有负观测相容；n<16 的反事实还留有一个源的数量余量。

安全的全频道免测条件为

\[
A\subseteq\bigcup_{q\in N_c}\overline B(q,1000-10^{-5}).\tag{1}
\]

若 c 仍未发现，(1) 蕴含 `F_c=∅`，于是其余站对 c 的全部测量均可免除。若源真的存在，它必落在某个已真实测量的保证接收盘中，当时就应被发现，与所有观测为负矛盾。

用户提出的“未排除可行域被已访问站的盘并集覆盖”是充分条件，但必须绑定**本频道在这些站确实测过**。若可行域已经按同一组负观测排除了这些盘，则它与这些盘不相交；要求它又被这些盘覆盖，实际上要求可行域为空。它不会从同一份负信息额外产生一次覆盖。

实现更保守地要求每个连续叶格整体落在一个已测盘中；可能拒绝一些由多个盘共同覆盖同一叶格的合法情况，但绝不会放宽 1000 m。下面的精确反例说明本次零收益并非这种格划分保守性造成。

## 4. 为何原七站每次空频道 RF 都有不可替代的职责

七个整数见证为：

`(0,0), (1140,0), (570,987), (−570,987), (−1140,0), (−570,−987), (570,−987)`。

见证 `w_j` 均在闭源盘内，满足

\[
\|w_j-p_j\|<1000,\qquad
\forall i\ne j:\ \|w_j-p_i\|>1000.\tag{2}
\]

全部平方距离以精确分数存于证书，而不是用格点覆盖采样代替证明。对空频道 c，删去 `(p_j,c)` 后，在 `w_j` 添加一个半径 1000 的源，其他六站对 c 仍全部返回阴性。其他频道的观测和清除不受影响；原局 n<16 时新局 n+1 仍合法。

因此，对固定七个查询位置的任意子集，只要未测某站，就有与其余该频道负观测相容的合法源位置。即使允许等待其他所有六站都测完，也不能删除第七站。这比“运行时没触发免测”更强，但没有扩展到自由移动扫描点或任意六盘布局。

另做 **42 组反事实负测试**：取独立验证首六局（n=10…15），逐站删除某空频道一次 RF，并分别回放“原空频道世界”和“添加上述源的世界”。**剩余请求对应的全部公开响应相同，包括虚拟时间，仅排除实时时间戳；新增源在故意删测的世界中被漏掉。** 原场景、添加源、删测索引和两份回放轨迹均可重建，原始双轨迹位于 [counterfactuals](counterfactuals)，索引见 [audit.json](audit.json)。

这些是故意破坏策略的反例测试，预期出现漏源，不计入候选成绩。下文所有基线及候选整局运行均要求全清。
