## 输入与误差

坐标和距离使用米，接口示向角使用度。各观测包含检测位置、示向角及角误差半宽；示例和完整字段见 [standard.json](../algorithms/q1q2/data/standard.json)，搜索参数见 [default_config.json](../algorithms/q1q2/data/default_config.json)。多站观测针对同一静止源。

理论示向误差半宽为 1°。若明确采用“误差后最近舍入到 0.01°”的读数模型，可用 1.005° 外包；这需要相应的舍入假设，不能由显示位数直接推出。Q3/Q4 的实际实现使用 1.01°，与 Q1/Q2 理论场景分别记录。同点同源在稳定阶段重复检测使用固定反馈，不能通过重复取平均缩小误差界。

## Q1：几何定位与圆覆盖

每条朝前角锥写成两个闭半平面，取全部约束的交集。程序区分空集、点、线段、有界多边形与无界集；数值未决单独返回。不得用绘图窗口截断无界区域，也不得将空集视作定位完成。

有界凸区域的直径可由顶点对求出。设直径为 d，最小覆盖圆半径为 R，则 d/2 ≤ R ≤ d/√3。以某对直径端点的中点为圆心、d/2 为半径，并不总能包含区域；程序单独检查覆盖。

20 米清除对应 R ≤ 20。d ≤ 20√3 是充分条件，d > 40 时不可能，中间区间要检查形状。最小覆盖圆的圆心与半径必须成对使用，不能把检测位置换作圆心后继续沿用该半径。

几何内核按输入所表示的数值进行分类和谓词计算，保留精确算术结果与浮点展示量的区别；独立基准明确自己的有理输入或高精度角函数语义。测试通过不代表认证了任意病态的超越数输入。

## Q2：保收域与最坏定位直径

先将首测角锥、目标区域、首次成功接收及近场规则合成源位置可行集 F。接收半径固定未知，取值在 [1000,1500] 米；近场半径 5 米，清除半径 20 米。候选第二站 q 必须满足行动约束，并对与首测相容的源和接收半径保证收到信号，形成保收域 C_sig。

标准首测为 S=(0,0)、示向 0°、半宽 1°，目标圆半径 1800 米。此时保收域等于以 5u± 和 1000u± 为圆心、半径 1000 米的四个圆盘的交，其中 u±=(cos1°,±sin1°)。首次可行集被场地裁剪时，应使用通用候选检查，不能直接套用四圆盘化简。

对 q≠S，目标 J(q) 是可能产生同一第二反馈的源位置对的最大间距。near 与 direction 分支分别计算；同点重复观测 q=S 使用固定反馈规则。该目标是最坏定位直径，不是平均误差、实际真源误差或最坏覆盖半径。

求解先扫描候选网格和边界，再从分散起点局部细化，并补入边界接触源对。不同候选在公共样本上复评。输出包含候选可行性、源对见证、细化变化、停止原因与稳定性状态。`NUMERICAL_CANDIDATE` 表示数值候选；有限源样本的最大距离只能支持对应样本的结论。

## 数值认证与移动预算

固定点认证给出 J(q) 的包含区间；外层认证对标准场景证明所有可行第二站的下界。两者不能互相替代。现存证书给出 110.960101 ≤ inf J(q) ≤ 110.970102 米（展示端点向外取整），精确上下界差为 0.01 米。它不证明推荐坐标唯一或具有某种坐标精度，也不外推到非标准首测。

检测点的移动预算以米计，移动时间为距离/5，另加 5 秒检测时间。理论最优值随预算增大不增；有限搜索所得推荐点未必单调改善，需结合公共样本复评和停止状态解释。条件反馈下的覆盖半径不能写成全部反馈的最坏覆盖半径。

## 运行与复核

从仓库根目录执行：

```sh
python -m algorithms.q1q2.run q1 algorithms/q1q2/data/standard.json --output outputs/q1
python -m algorithms.q1q2.run q2 algorithms/q1q2/data/standard.json --config algorithms/q1q2/data/default_config.json --output outputs/q2
python -m pytest algorithms/q1q2/tests -q --import-mode=importlib
python -m algorithms.q1q2.benchmarks.q2_outer.exclusion_run verify
```

求解输出目录须不存在。`verify` 读取已保存的外层证书并重算校验结果，不调用官方模拟器。完整外层搜索步骤见 [外层实验说明](../algorithms/q1q2/benchmarks/q2_outer/README.md)，敏感性设置与结果见 [数学敏感性实验](../algorithms/q1q2/reviews/sensitivity/README.md)。Q3/Q4 的官方实验另见 [experiments/README.md](../experiments/README.md)。
