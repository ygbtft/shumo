# Q1：由有界示向误差建立位置可行域

输入是检测位置、示向角及明确的角误差上界。每次观测给出一个朝前的角锥；将两条边界写成半平面，所有半平面的交得到位置可行域。`geometry.py` 区分空集、点、线段、有界多边形和无界域，保留数值未决状态。

对有界域计算直径与最小覆盖圆。直径决定区域最远两点的距离，但半径为直径一半的圆不一定覆盖整个区域；必须进一步验证圆覆盖。记直径为 d、最小覆盖圆半径为 R，则 d/2≤R≤d/√3。20米统一清除要求存在一个落点到全部可行位置的距离不超过20米，即 R≤20。

因此 d≤20√3 时必可统一清除，d>40时不可能；中间区间必须看区域形状和实际覆盖圆。空域代表输入矛盾或模型假设不相容，不能当作已经完成定位。

代码：`algorithms/q1q2/{geometry,circle,q1}.py`。输入解析在`adapters.py`，入口是`python -m algorithms.q1q2.run q1 ...`。四个基本角度/距离函数在`basic_geometry.py`，不依赖模拟器。

实验：`algorithms/q1q2/benchmarks/q1_geometry/`与`q1_circle_cover/`保留独立真值、案例和结果；`tests/`保留回归用例。完整模型设计见[q1q2-design.md](q1q2-design.md)。
