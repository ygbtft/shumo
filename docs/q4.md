# Q4：含定向源时的覆盖、成对探测与任务调度

唯一交付算法固定为第二次正式测试方案：最近邻任务排序、35米提前试清门限；fraction=0.15、share_limit=6、share_cooldown=150、transverse_m=40、steps=10、pause_limit=16。fraction=0.30与share_limit=2的组合仅是参数组合对照，不属于交付baseline。

全向七站覆盖不能直接用于未知朝向的定向源。Q4使用经过验证的21站布局`layouts/grid21_29.json`，对源区域和允许朝向保证搜索覆盖。示向正反馈仍用于位置可行域裁剪，但无信号可能来自距离或朝向，不能机械套用Q3的全向距离排除规则。

定位采用有界成对探测，结合实际正负反馈缩小位置范围；横向距离与前进比例控制探针几何。已发现源、扫描站和清除任务共同调度，顺路共享测量，负反馈冷却避免低收益重复测量。最近邻选择任务，认证清除及光学兜底维持完成条件。

代码由`algorithms/q34/strategy.py`构造`CoupledWidthPolicy`，核心涉及`coupled_dispatch_policy.py`、`bounded_width_policy.py`、`bracket_policy.py`等；`integer_visibility_certificate.py`与`visibility_certificate.py`为独立覆盖验证工具。

官方调试入口：`interfaces/official.py --problem 4`。第二次正式记录见`data/formal/q4/attempt2/`，清除16个，官方总虚拟时间4023.825450秒。三次记录全部保留，但论文主方案身份以第二次为准。
