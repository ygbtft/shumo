# Q2：选择保证接收且最坏定位范围较小的第二检测点

先由首测及物理边界构造源位置可行集，再求第二检测位置的候选域：该点必须在动作范围内，并对首测仍可能对应的源保证接收。标准对称场景可以约化为四个圆盘的交；一般首测受场地裁剪时使用通用可行性判断，不能套用标准场景的约化。

对候选检测点 q，将可能产生同一第二反馈的两个源位置作为一对。它们的最大间距就是该反馈模型下的最坏定位直径目标 J(q)。near反馈与direction反馈分别处理；同点重复测量采用固定反馈语义，不把重复读数错误地当成独立新信息。

求解使用候选网格、边界/局部细化及点对搜索，再在共同样本上公平复评。数值搜索返回`NUMERICAL_CANDIDATE`等状态；有限源采样给出的目标值不能直接作为全域最优证明。`optional/certified.py`提供固定点J(q)的区间上下界，`optional/outer_exclusion.py`对标准场景提供外层排除认证，两种证明范围分别说明。

代码：`algorithms/q1q2/{feasible,q2,diagnostics}.py`。入口是`python -m algorithms.q1q2.run q2 ...`。`sensitivity.py`保留参数与数学假设的敏感性运行器。

已保存认证可独立复核：

```sh
python -m algorithms.q1q2.benchmarks.q2_outer.exclusion_run verify
```

该命令重写派生的`verification.json`，不重新搜索或调用模拟器。对应案例、证书、数值结果在`benchmarks/q2_candidate/`、`q2_worst_diameter/`、`q2_outer/`。
