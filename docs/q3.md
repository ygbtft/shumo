# Q3：全向干扰源的搜索、定位与清除

唯一交付算法固定为第二次正式测试方案：最近邻任务排序、65米提前试清门限、每个源主定位预算2轮；share_limit=6、localization_weight=0.08、remainder_weight=1.5。

搜索采用中心点加半径1140米的六环站，共七站。利用全向接收半径下界保证整个源区域受到覆盖；站点顺序与源服务任务联合安排。每次收到实际示向反馈后用有界角锥裁剪可行位置，真实阴性与正反馈锚点形成距离支配约束；定位和停止决策只使用公开反馈。

从待扫描站、已发现源定位任务和可清除任务中按最近邻规则选下一步，并在经过的位置补测其他已知源。65米是允许失败的提前试清策略门限，官方清除距离仍是20米。主定位2轮是策略预算，不是全流程所有测量次数的上限；认证清除与有限光学兜底保留。

`algorithms/q34/strategy.py`构造`OmniNegativeCompletionPolicy`；具体实现通过既有继承链复用扫描、定位、共享观测、光学清除等模块。核心计算代码和浮点站坐标与第二次正式测试源码一致。

官方调试入口：`interfaces/official.py --problem 3`。第二次正式记录见`data/formal/q3/attempt2/`；三次原始记录均由`data/formal/index.json`索引。第二次清除14个，官方总虚拟时间2943.746632秒。正式界面未披露真实源数，不单凭清除数断言官方全清。

消融、参数实验的two_opt排序组与第二次正式方案的最近邻组属于不同设置。实验统计使用第二次正式方案同配置的10局演练均值作基准，正式单局数据不混入该均值。统计方法和复现入口见[实验说明](../experiments/README.md)。
